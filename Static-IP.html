১ ওভারভিউ ও স্কোপ

▼

Static IP (স্ট্যাটিক আইপি) হলো এমন একটি IP অ্যাড্রেস যা ম্যানুয়ালি নির্ধারণ করা হয় এবং পরিবর্তন হয় না। DHCP-এর মতো স্বয়ংক্রিয়ভাবে বরাদ্দ না হয়ে, নেটওয়ার্ক অ্যাডমিনিস্ট্রেটর একটি নির্দিষ্ট ডিভাইসকে সবসময় একই IP দেন। MikroTik RouterOS-এ WinBox GUI এবং CLI-এর মাধ্যমে সহজেই Static IP কনফিগার করা যায়।

স্কোপ (Scope)

  • অন্তর্ভুক্ত: Static IP-এর মূল ধারণা, WinBox-এ কনফিগারেশন, ISP/NOC স্ট্যাটিক IP প্ল্যানিং, Multiple IP, Routing, ভেরিফিকেশন এবং Troubleshooting।
  • বাদ: DHCP সার্ভার বিস্তারিত, PPPoE, Hotspot (আলাদা টপিক)।
  • ভার্সন: MikroTik RouterOS (v7 prioritized), WinBox GUI।
ℹ️ তথ্য ISP/NOC পরিবেশে Static IP অত্যন্ত গুরুত্বপূর্ণ — সার্ভার, রাউটার, প্রিন্টার, CCTV ক্যামেরা এবং কাস্টমার CPE-গুলোতে সবসময় একই IP দরকার হয় যাতে রিমোট অ্যাক্সেস ও মনিটরিং সহজ হয়।

২ পাঁচটি প্রধান স্তম্ভ (Five Priority Pillars)

▼
  1. ধারণা ও কনফিগারেশন: Static IP কী, কেন দরকার, এবং WinBox-এ ধাপে ধাপে কনফিগারেশন।
  2. ভেন্ডর-স্পেসিফিক কমান্ড: MikroTik RouterOS-এর সঠিক CLI কমান্ড এবং WinBox মেনু পাথ।
  3. হ্যান্ডস-অন ল্যাব: বাস্তব ISP/NOC টপোলজি, IP প্ল্যান, কনফিগারেশন এবং টেস্ট।
  4. ভেরিফিকেশন ও Troubleshooting: প্রতিটি ধাপ যাচাই এবং সমস্যা সমাধান।
  5. বেস্ট প্র্যাকটিস ও সতর্কতা: ISP/NOC IP প্ল্যানিং, স্ট্যাটিক IP ডিজাইন এবং প্রোডাকশন সতর্কতা।

৫ ELI10 ও ELI15

▼

ELI10 (সহজ উপমা)

ভাবুন, আপনার বাড়ির ঠিকানা হলো Static IP। আপনার বাড়ির ঠিকানা কখনো বদলায় না — চিঠি পাঠালে সবসময় একই ঠিকানায় পৌঁছায়। অন্যদিকে Dynamic IP হলো হোটেলের রুম নম্বর — চেক-ইন করলে একটা রুম পান, চেক-আউট করলে সেটা চলে যায়, পরেরবার ভিন্ন রুম পান। সার্ভার, প্রিন্টার বা CCTV-এর জন্য Static IP দরকার যাতে সবসময় একই ঠিকানায় পাওয়া যায়।

ELI15 (প্রযুক্তিগত)

Static IP হলো একটি নির্দিষ্ট IPv4 অ্যাড্রেস যা ম্যানুয়ালি একটি ইন্টারফেসে অ্যাসাইন করা হয়। MikroTik-এ WinBox → IP → Addresses-এ CIDR নোটেশন (যেমন 192.168.10.10/24) দিয়ে IP কনফিগার করা হয়। RouterOS স্বয়ংক্রিয়ভাবে connected route তৈরি করে এবং ARP-এর মাধ্যমে MAC অ্যাড্রেস রিজলভ করে। গেটওয়ে সেট করতে হয় যাতে অন্য সাবনেটে ট্রাফিক পাঠানো যায়। Static IP-তে IP conflict এড়াতে অবশ্যই সঠিক ডকুমেন্টেশন ও IP প্ল্যানিং প্রয়োজন।

৭ কেন ও কীভাবে (WHY & HOW)

▼

কেন Static IP?

  • স্থায়িত্ব: সার্ভার, প্রিন্টার, CCTV-এর ঠিকানা সবসময় একই থাকে।
  • রিমোট অ্যাক্সেস: বাইরে থেকে সার্ভারে কানেক্ট করা যায়।
  • DNS/ডোমেইন: ডোমেইন নামের সাথে IP ম্যাপ করা সহজ।
  • ম্যানেজমেন্ট: রাউটার/সুইচের ম্যানেজমেন্ট IP স্থির থাকে।

কীভাবে কাজ করে?

  1. একটি নির্দিষ্ট IP, সাবনেট মাস্ক এবং গেটওয়ে নির্ধারণ করুন।
  2. WinBox → IP → Addresses-এ IP যোগ করুন।
  3. RouterOS স্বয়ংক্রিয়ভাবে connected route তৈরি করে।
  4. ARP টেবিলে IP ↔ MAC ম্যাপিং জমা হয়।
  5. গেটওয়ে দিয়ে অন্য নেটওয়ার্কে ট্রাফিক যায়।

১৩ Multiple IP ও Secondary IP

▼

একই ইন্টারফেসে একাধিক সাবনেট

MikroTik RouterOS-এ একই ইন্টারফেসে ভিন্ন সাবনেটের একাধিক IP দেওয়া যায়। এটাকে Secondary IP বলে।

RouterOS — Secondary IP
/ip address add address=192.168.10.1/24 interface=ether2 comment="Primary"
/ip address add address=192.168.20.1/24 interface=ether2 comment="Secondary"
ℹ️ তথ্য Secondary IP তখন দরকার হয় যখন একই ইন্টারফেসে দুটি ভিন্ন সাবনেটের ক্লায়েন্টদের সার্ভ করতে হয় — যেমন Guest ও Staff নেটওয়ার্ক একটি ইন্টারফেসে।

১৯ সিকিউরিটি

▼

Static IP সিকিউরিটি

  • ARP Mode: /ip settings set arp=reply-only দিয়ে ARP spoofing প্রতিরোধ।
  • IP Conflict: DHCP-এ conflict-detection চালু রাখুন।
  • Management IP: WinBox অ্যাক্সেস শুধু নির্দিষ্ট সাবনেটে সীমিত করুন।
  • Documentation: প্রতিটি Static IP-এর কমেন্টে ডিভাইসের নাম লিখুন।
🛡️ NOC টিপ ISP/NOC-এ Static IP-এর তালিকা রাখুন IPAM টুলে। একটি IP দুইজনকে দিলে IP conflict হবে এবং সার্ভিস ডাউন হবে।

২২ ফেইলিওর সিমুলেশন

▼

সিমুলেশন ১: ভুল গেটওয়ে

সিম্পটম: LAN-এ ping যায়, কিন্তু ইন্টারনেটে যায় না।
কারণ: ডিফল্ট গেটওয়ে ভুল সেট করা।
ফিক্স: /ip route add dst-address=0.0.0.0/0 gateway=192.168.10.1

সিমুলেশন ২: IP Conflict

সিম্পটম: মাঝে মাঝে সংযোগ বিচ্ছিন্ন হয়।
কারণ: দুই ডিভাইসে একই Static IP।
ফিক্স: IP প্ল্যান ডকুমেন্ট করে ইউনিক IP দিন।

সিমুলেশন ৩: DHCP পুলে Static IP

সিম্পটম: DHCP ক্লায়েন্ট একটি IP পায় যা অন্য ডিভাইসের Static IP-এর সাথে conflict করে।
ফিক্স: Static IP DHCP পুলের বাইরে রাখুন।

সিমুলেশন ৪: WinBox লকআউট

সিম্পটম: LAN IP পরিবর্তনের পর WinBox সংযোগ নেই।
ফিক্স: কনসোল/সিরিয়াল থেকে /ip address print চেক করুন।

সিমুলেশন ৫: ARP সমস্যা

সিম্পটম: একই সাবনেটে ping যায় না।
চেক: /ip arp print → MAC দেখা যাচ্ছে না।
ফিক্স: কেবল/সুইচ চেক করুন, ARP mode ঠিক করুন।

২৩ বেস্ট প্র্যাকটিস

▼

ল্যাব vs প্রোডাকশন

দিকল্যাবপ্রোডাকশন (ISP/NOC)
IP প্ল্যানযেকোনোডকুমেন্টেড, স্কেলযোগ্য
Static IPপরীক্ষামূলকDHCP পুলের বাইরে
ব্যাকআপস্ন্যাপশটনিয়মিত এক্সপোর্ট
পরিবর্তনস্বাধীনচেঞ্জ উইন্ডো
ডকুমেন্টেশনঐচ্ছিকবাধ্যতামূলক

মূল সুপারিশ

  • IP প্ল্যান ডকুমেন্ট করুন (Static IP তালিকা)।
  • DHCP পুলের বাইরে Static IP রাখুন।
  • প্রতিটি IP-এর কমেন্টে ডিভাইসের নাম লিখুন।
  • নিয়মিত কনফিগারেশন এক্সপোর্ট নিন।

২৪ NOC সিনারিও

▼

সিনারিও: একটি ISP-তে নতুন CCTV সার্ভার যোগ করার পর কিছু ক্লায়েন্ট ইন্টারনেট পাচ্ছে না।

প্রথম চেক: ক্লায়েন্টরা IP পেয়েছে কিনা দেখুন — /ip dhcp-server lease print।

রুট কজ: নতুন CCTV-এর Static IP DHCP পুলের ভেতরে দেওয়া হয়েছে, ফলে DHCP ক্লায়েন্ট একই IP পেয়ে conflict হয়েছে।

সমাধান: Static IP DHCP পুলের বাইরে সরান: 192.168.10.250/24

প্রতিরোধ: DHCP পুলের বাইরে Static IP রাখা বাধ্যতামূলক করুন এবং IP প্ল্যান ডকুমেন্ট করুন।

২৫ বিগিনার ল্যাব

▼

Beginner

উদ্দেশ্য

WinBox-এ একটি Static IP কনফিগার করা এবং ক্লায়েন্ট থেকে ping করা।

টপোলজি

Client PC (192.168.10.10/24) → Router (192.168.10.1/24)

ধাপ

  1. WinBox → IP → Addresses → +।
  2. Address: 192.168.10.10/24, Interface: ether2।
  3. ক্লায়েন্ট PC-তে IP: 192.168.10.100/24, Gateway: 192.168.10.1।
  4. ক্লায়েন্ট থেকে ping 192.168.10.10 টেস্ট করুন।

সফলতার মাপকাঠি

২৬ ইন্টারমিডিয়েট ল্যাব

▼

Intermediate

উদ্দেশ্য

একাধিক Static IP (সার্ভার, প্রিন্টার, CCTV) কনফিগার করা এবং DHCP পুলের বাইরে রাখা।

ধাপ

  1. /ip address add address=192.168.10.10/24 interface=ether2 comment="Server"
  2. /ip address add address=192.168.10.20/24 interface=ether2 comment="CCTV"
  3. /ip address add address=192.168.10.30/24 interface=ether2 comment="Printer"
  4. DHCP পুল: 192.168.10.100-200
  5. প্রতিটি ডিভাইস থেকে ping টেস্ট করুন।

সফলতার মাপকাঠি

২৭ অ্যাডভান্সড ল্যাব

▼

Advanced

উদ্দেশ্য

Static IP, DHCP এবং Routing একসাথে কনফিগার করে একটি সম্পূর্ণ ISP/NOC নেটওয়ার্ক তৈরি করা।

ধাপ

  1. WAN: /ip address add address=203.0.113.2/30 interface=ether1
  2. LAN: /ip address add address=192.168.10.1/24 interface=ether2
  3. Server: /ip address add address=192.168.10.10/24 interface=ether2
  4. DHCP: /ip dhcp-server কনফিগার করুন।
  5. NAT: /ip firewall nat add chain=srcnat out-interface=ether1 action=masquerade
  6. Gateway: /ip route add dst-address=0.0.0.0/0 gateway=203.0.113.1

চ্যালেঞ্জ

Static IP ও DHCP পুলের মধ্যে conflict এড়াতে IP প্ল্যান ডকুমেন্ট করুন।

২৮ ইন্টারভিউ প্রশ্ন

▼

বিগিনার

প্রশ্ন ১: Static IP কী?
উত্তর: ম্যানুয়ালি নির্ধারিত স্থায়ী IP অ্যাড্রেস।

প্রশ্ন ২: Static ও Dynamic IP-এর পার্থক্য?
উত্তর: Static স্থায়ী, Dynamic পরিবর্তনশীল।

প্রশ্ন ৩: WinBox-এ Static IP কোথায় কনফিগার হয়?
উত্তর: IP → Addresses।

ইন্টারমিডিয়েট

প্রশ্ন ৪: DHCP পুলের বাইরে Static IP কেন রাখবেন?
উত্তর: IP conflict এড়াতে।

প্রশ্ন ৫: Secondary IP কী?
উত্তর: একই ইন্টারফেসে ভিন্ন সাবনেটের দ্বিতীয় IP।

প্রশ্ন ৬: Static IP-এর কমেন্ট কেন দরকার?
উত্তর: ডকুমেন্টেশন ও ম্যানেজমেন্টের জন্য।

অ্যাডভান্সড

প্রশ্ন ৭: IP conflict হলে কী হবে?
উত্তর: দুটি ডিভাইসের মধ্যে কানেক্টিভিটি বিঘ্নিত হবে, ping ফ্ল্যাপ করবে।

প্রশ্ন ৮: একই ইন্টারফেসে একাধিক সাবনেট দেওয়া যায়?
উত্তর: হ্যাঁ, Secondary IP দিয়ে।

প্রশ্ন ৯: ISP/NOC-এ Static IP কোথায় ব্যবহার হয়?
উত্তর: সার্ভার, CCTV, প্রিন্টার, রাউটার ম্যানেজমেন্ট, কাস্টমার CPE।
