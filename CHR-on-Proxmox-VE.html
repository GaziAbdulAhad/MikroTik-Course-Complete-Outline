১ ওভারভিউ ও স্কোপ

▼

MikroTik CHR (Cloud Hosted Router) হলো RouterOS-এর একটি ভার্চুয়ালাইজড সংস্করণ, যা x86_64 ভার্চুয়াল পরিবেশে চলার জন্য ডিজাইন করা হয়েছে। Proxmox VE হলো একটি ওপেন-সোর্স এন্টারপ্রাইজ ভার্চুয়ালাইজেশন প্ল্যাটফর্ম যা KVM এবং LXC ব্যবহার করে। Proxmox-এ CHR ইনস্টল করলে আপনি একটি সম্পূর্ণ কার্যকর RouterOS ইনস্ট্যান্স পাবেন, যা প্রোডাকশন রাউটার হিসেবে বা ল্যাব টেস্টিংয়ের জন্য ব্যবহার করা যায়।

স্কোপ (Scope)

  • অন্তর্ভুক্ত: Proxmox VE-তে CHR ইমেজ ডাউনলোড, qcow2 কনভার্সন, VM তৈরি, সিরিয়াল কনসোল কনফিগারেশন, প্রাথমিক বুট, নেটওয়ার্কিং, লাইসেন্সিং, ভেরিফিকেশন, Troubleshooting এবং প্রোডাকশন বেস্ট প্র্যাকটিস।
  • বাদ: EVE-NG/VirtualBox/VMware-এ ইনস্টলেশন (আলাদা টপিক), জটিল রাউটিং প্রোটোকল (BGP/OSPF) কনফিগারেশন, এবং ফিজিক্যাল MikroTik হার্ডওয়্যার।
  • ভার্সন: RouterOS v7.x (CHR)। v6-এর সাথে গুরুত্বপূর্ণ পার্থক্য থাকলে উল্লেখ করা হবে।
ℹ️ তথ্য CHR-এর ফ্রি লাইসেন্সে প্রতি ইন্টারফেসে ১ Mbps থ্রুপুট সীমা আছে। ল্যাব ও শেখার জন্য যথেষ্ট, কিন্তু থ্রুপুট টেস্টিং বা প্রোডাকশনের জন্য পেইড লাইসেন্স বা ৬০ দিনের ট্রায়াল প্রয়োজন। Proxmox-এ CHR চালানোর জন্য সিরিয়াল কনসোল (--serial0 socket --vga serial0) কনফিগার করা বাধ্যতামূলক — নইলে কনসোল কালো দেখাবে [citation:10]।

  3. হ্যান্ডস-অন ল্যাব: বাস্তব টপোলজি, কনফিগারেশন এবং টেস্ট।
  4. ভেরিফিকেশন ও Troubleshooting: প্রতিটি ধাপ যাচাই এবং সমস্যা সমাধান।

৪ আর্কিটেকচার ও টপোলজি

▼

Proxmox VE-তে CHR-এর সাধারণ টপোলজি

Proxmox Host (Debian) → KVM/QEMU → CHR VM (qcow2)

Network Bridges:
vmbr0 (WAN) ↔ CHR net0
vmbr1 (LAN) ↔ CHR net1

কম্পোনেন্ট

  • Proxmox Host: Debian-ভিত্তিক লিনাক্স সার্ভার যেখানে Proxmox VE ইনস্টল করা আছে।
  • KVM/QEMU: ভার্চুয়ালাইজেশন ইঞ্জিন যা CHR VM চালায়।
  • CHR qcow2: Proxmox-এর স্টোরেজে সংরক্ষিত CHR ডিস্ক ইমেজ।
  • vmbr0/vmbr1: Proxmox-এর ভার্চুয়াল নেটওয়ার্ক ব্রিজ।

৫ ELI10 ও ELI15

▼

ELI10 (সহজ উপমা)

ভাবুন, আপনার Proxmox সার্ভার হলো একটি বড় অ্যাপার্টমেন্ট বিল্ডিং। প্রতিটি ফ্ল্যাট হলো একটি ভার্চুয়াল মেশিন (VM)। CHR হলো সেই বিল্ডিংয়ের একটি ফ্ল্যাটে রাখা একটি ছোট রাউটার — যা দেখতে ভার্চুয়াল, কিন্তু কাজ করে আসল MikroTik রাউটারের মতোই। আপনাকে শুধু CHR-এর ডিস্ক ইমেজটি Proxmox-এর সঠিক জায়গায় রাখতে হবে, তারপর Proxmox-এর ওয়েব ইন্টারফেস থেকে একটি ফ্ল্যাট (VM) তৈরি করে সেটি অ্যাটাচ করলেই কাজ শেষ।

ELI15 (প্রযুক্তিগত)

Proxmox VE KVM-ভিত্তিক ভার্চুয়াল মেশিন চালায়। CHR-এর অফিসিয়াল Raw ডিস্ক ইমেজ (.img) ডাউনলোড করে qemu-img convert দিয়ে qcow2 ফরম্যাটে রূপান্তর করতে হয়। তারপর Proxmox-এর qm set বা qm importdisk কমান্ড দিয়ে VM-এ অ্যাটাচ করতে হয়। গুরুত্বপূর্ণ: CHR সিরিয়াল কনসোলে আউটপুট দেয়, তাই VM-এ --serial0 socket --vga serial0 কনফিগার করতে হয়, নইলে Proxmox কনসোল কালো দেখাবে [citation:10]। CHR বুট হলে RouterOS তার নিজস্ব IP স্ট্যাক, ফায়ারওয়াল ও রাউটিং টেবিল নিয়ে চলে, এবং WinBox/SSH/WebFig দিয়ে ম্যানেজ করা যায়।

৭ কেন ও কীভাবে (WHY & HOW)

▼

কেন Proxmox-এ CHR?

  • প্রোডাকশন-গ্রেড: Proxmox এন্টারপ্রাইজ-গ্রেড হাইপারভাইজার, CHR প্রোডাকশন রাউটার হিসেবে ব্যবহারযোগ্য।
  • ফ্রি ও ওপেন: Proxmox VE ফ্রি (সাবস্ক্রিপশন ছাড়া) এবং CHR-এর ফ্রি লাইসেন্সও ফ্রি।
  • স্কেল: একাধিক CHR ইনস্ট্যান্স, HA ক্লাস্টার, ব্যাকআপ সাপোর্ট।
  • শেখা ও টেস্টিং: আসল রাউটার ভাঙার ভয় ছাড়াই কনফিগারেশন টেস্ট করা যায়।

কীভাবে কাজ করে?

  1. CHR-এর Raw ডিস্ক ইমেজ (.img) ডাউনলোড করা হয়।
  2. qemu-img convert দিয়ে qcow2 ফরম্যাটে রূপান্তর করা হয়।
  3. Proxmox-এ VM তৈরি করে ডিস্ক অ্যাটাচ করা হয় (qm set বা qm importdisk)।
  4. সিরিয়াল কনসোল (--serial0 socket --vga serial0) কনফিগার করা হয়।
  5. VM বুট হলে RouterOS কার্নেল লোড হয়, Virtual NIC-গুলো ether ইন্টারফেস হিসেবে দেখা যায়।
  6. RouterOS তার নিজস্ব নেটওয়ার্কিং স্ট্যাক নিয়ে স্বাভাবিকভাবে কাজ করে।

৮ পূর্বশর্ত (Prerequisites)

▼

Proxmox হোস্ট

  • Proxmox VE ইনস্টল করা ও চলমান (সংস্করণ ৭.x বা ৮.x)।

  • পর্যাপ্ত ডিস্ক স্পেস (CHR ইমেজের জন্য ~১২৮ MB + qcow2 কপি)।
  • KVM ভার্চুয়ালাইজেশন চালু।

ফাইল

  • MikroTik CHR Raw disk image (chr-7.x.x.img.zip) — mikrotik.com/download থেকে [citation:1]।
  • SSH ক্লায়েন্ট (Proxmox হোস্টে অ্যাক্সেসের জন্য)।

# CHR ইমেজ ডাউনলোড (ভার্সন নম্বর আপডেট করুন)
wget https://download.mikrotik.com/routeros/7.21.4/chr-7.21.4.img.zip

ধাপ ৩: VM তৈরি (CLI পদ্ধতি)

Proxmox Host — Create VM
# VM তৈরি করুন (VMID=100 উদাহরণ)
qm create 100 --name chr-router --ostype l26 \
  --memory 512 --cores 1 --cpu host

# নেটওয়ার্ক কনফিগার (virtio, vmbr0)
qm set 100 --net0 virtio,bridge=vmbr0

# সিরিয়াল কনসোল (বাধ্যতামূলক!)
qm set 100 --serial0 socket --vga serial0

# ডিস্ক ইমপোর্ট (local-lvm স্টোরেজ উদাহরণ)
qm importdisk 100 chr-7.21.4.img local-lvm

# ইমপোর্ট করা ডিস্ক VM-এ অ্যাটাচ করুন
qm set 100 --scsi0 local-lvm:vm-100-disk-0

# বুট অর্ডার সেট করুন
qm set 100 --boot order=scsi0 --scsihw virtio-scsi-single
ℹ️ তথ্য qm importdisk কমান্ড ইমেজকে স্বয়ংক্রিয়ভাবে qcow2-এ কনভার্ট করে এবং স্টোরেজে রাখে। পুরনো Proxmox সংস্করণে ম্যানুয়াল qemu-img convert প্রয়োজন হতে পারে [citation:1]।

একাধিক নেটওয়ার্ক ব্রিজ

Proxmox-এ একাধিক ব্রিজ (vmbr0, vmbr1) তৈরি করে CHR-এ একাধিক NIC যোগ করা যায়।

Proxmox Host — Add Second NIC

ফায়ারওয়াল বেসিক

RouterOS v7 — বেসিক ফায়ারওয়াল রুল
/ip firewall filter
add chain=input action=accept connection-state=established,related
add chain=input action=accept protocol=tcp dst-port=8291 src-address=192.168.10.0/24
add chain=input action=drop in-interface=ether1
⚠️ সতর্কতা শেষ রুলটি ether1 (WAN) থেকে সব ইনপুট ড্রপ করে। নিশ্চিত করুন যে আপনি LAN/Management ইন্টারফেস দিয়ে অ্যাক্সেস রাখছেন, নইলে লকআউট হতে পারেন।

প্রাথমিক হার্ডেনিং

  • পাসওয়ার্ড: প্রথম লগইনে admin-এর পাসওয়ার্ড সেট করুন।
  • WinBox পোর্ট: ডিফল্ট 8291 পরিবর্তন করুন অথবা IP-দ্বারা সীমিত করুন।
  • Firewall: শুধুমাত্র বিশ্বস্ত সোর্স থেকে ম্যানেজমেন্ট অ্যাক্সেস অনুমোদন করুন।
  • Services: অপ্রয়োজনীয় সার্ভিস (Telnet, FTP) বন্ধ করুন।
RouterOS v7 — Disable Insecure Services
/ip service disable telnet,ftp,www
/ip service set winbox address=192.168.10.0/24
🛡️ NOC টিপ প্রোডাকশনে CHR ব্যবহার করলে WAN-এ রেখে বাইরে থেকে সরাসরি ম্যানেজমেন্ট অ্যাক্সেস দেবেন না। VPN বা ব্যাস্টিয়ন হোস্ট ব্যবহার করুন।

১৯ পারফরম্যান্স

▼

Proxmox পারফরম্যান্স টিউনিং

  • CPU: --cpu host ব্যবহার করুন যাতে হোস্টের রিয়েল CPU ফিচার পাওয়া যায় [citation:10]।
  • RAM: ৫১২ MB ন্যূনতম, ১০২৪ MB প্রস্তাবিত।
  • NIC টাইপ: virtio (প্যারাভার্চুয়ালাইজড) সর্বোত্তম পারফরম্যান্স দেয়।
  • SCSI কন্ট্রোলার: virtio-scsi-single ব্যবহার করুন, ডিফল্ট মাল্টি-কিউ নয় [citation:10]।
  • Storage: qcow2 ফাইল SSD-তে রাখুন।

লাইসেন্স থ্রুপুট সীমা

ফ্রি লাইসেন্সে ১ Mbps সীমা চালু থাকলে উচ্চ থ্রুপুট আশা করবেন না। /system license print দিয়ে লাইসেন্স যাচাই করুন।

২২ ফেইলিওর সিমুলেশন

▼

সিমুলেশন ১: কনসোল কালো

সিম্পটম: VM চলছে কিন্তু Proxmox কনসোলে কিছু দেখা যায় না।
কারণ: সিরিয়াল কনসোল কনফিগার করা হয়নি।
ফিক্স: qm set <VMID> --serial0 socket --vga serial0 চালান, তারপর VM রিস্টার্ট করুন [citation:10]।

সিমুলেশন ২: ভুল ডিস্ক ফরম্যাট

সিম্পটম: VM বুট হয় না, iPXE বা boot failed।
কারণ: .npk ফাইল ডাউনলোড করা হয়েছে, CHR Raw image নয়।
ফিক্স: mikrotik.com/download থেকে Cloud Hosted Router → Raw ডাউনলোড করুন।

সিমুলেশন ৩: ডিস্ক অ্যাটাচ সমস্যা

সিম্পটম: VM বুট হয় কিন্তু "no bootable device"।
কারণ: qm importdisk-এর পর ডিস্ক VM-এ অ্যাটাচ করা হয়নি।
ফিক্স: qm set <VMID> --scsi0 <storage>:vm-<VMID>-disk-0 এবং --boot order=scsi0।

সিমুলেশন ৪: নেটওয়ার্ক সংযোগ নেই

সিম্পটম: ether1 আছে কিন্তু IP নেই।
কারণ: DHCP client কনফিগার করা হয়নি অথবা vmbr0-তে DHCP নেই।
ফিক্স: /ip dhcp-client add interface=ether1 disabled=no অথবা স্ট্যাটিক IP দিন।

সিমুলেশন ৫: লাইসেন্স আপগ্রেড ব্যর্থ

সিম্পটম: /system/license/renew ব্যর্থ হচ্ছে।
কারণ: MikroTik অ্যাকাউন্ট ভুল অথবা নেটওয়ার্ক থেকে MikroTik সার্ভারে অ্যাক্সেস নেই।
ফিক্স: অ্যাকাউন্ট ক্রেডেনশিয়াল চেক করুন, /ping account.mikrotik.com চালান।

  • /export নিয়মিত সংরক্ষণ করুন।
  • ফ্রি লাইসেন্সের সীমাবদ্ধতা সম্পর্কে সচেতন থাকুন।
  • WAN-এ রেখে বাইরে থেকে সরাসরি ম্যানেজমেন্ট অ্যাক্সেস দেবেন না।
  • --serial0 socket --vga serial0 সবসময় কনফিগার করুন [citation:10]।

২৪ প্রোডাকশন কনফিগারেশন

▼

প্রোডাকশনে CHR ব্যবহারের আগে:

  1. P1 বা তার বেশি লাইসেন্স কিনুন।
  2. Proxmox HA ক্লাস্টার কনফিগার করুন (ঐচ্ছিক কিন্তু সুপারিশকৃত)।
  3. ফায়ারওয়াল হার্ডেনিং প্রয়োগ করুন।
  4. নিয়মিত কনফিগারেশন ব্যাকআপ সেটআপ করুন।
  5. মনিটরিং (SNMP, Syslog) চালু করুন।
  6. Proxmox ব্যাকআপ স্ক্রিপ্ট দিয়ে নিয়মিত VM ব্যাকআপ নিন।
🚀 প্রোডাকশন Proxmox এন্টারপ্রাইজ-গ্রেড হাইপারভাইজার, CHR প্রোডাকশন রাউটার হিসেবে ব্যবহারযোগ্য। তবে নিশ্চিত করুন যে আপনার লাইসেন্স প্রোডাকশন থ্রুপুটের জন্য যথেষ্ট (P1 ন্যূনতম) এবং ফায়ারওয়াল হার্ডেনিং প্রয়োগ করা হয়েছে।

২৫ NOC সিনারিও

▼

সিনারিও: একটি ছোট ISP Proxmox-এ CHR ব্যবহার করে কাস্টমার ট্রাফিক রাউট করছে। হঠাৎ কাস্টমাররা ধীর গতির অভিযোগ করছে।

প্রথম চেক: /system license print → level: free।

রুট কজ: ফ্রি লাইসেন্স ১ Mbps সীমা।

সমাধান: P1 লাইসেন্স কিনে /system license renew চালান।

প্রতিরোধ: মনিটরিং সিস্টেমে লাইসেন্স স্তর ও থ্রুপুট সীমা অ্যালার্ট সেট করুন।

২৬ বিগিনার ল্যাব

▼

Beginner

উদ্দেশ্য

Proxmox VE-তে CHR ইনস্টল করে প্রথম বুট এবং vmbr0-এর মাধ্যমে নেটওয়ার্ক অ্যাক্সেস নিশ্চিত করা।

টপোলজি

Proxmox vmbr0 → CHR ether1 → Network

ধাপ

  1. CHR Raw image (.img.zip) ডাউনলোড করুন।
  2. Proxmox হোস্টে wget ও unzip চালান।
  3. qm create দিয়ে VM তৈরি করুন।
  4. qm set দিয়ে --serial0 socket --vga serial0 কনফিগার করুন।
  5. qm importdisk দিয়ে ডিস্ক অ্যাটাচ করুন।
  6. VM চালু করুন, admin/blank দিয়ে লগইন করুন।
  7. /interface print দিয়ে ether1 দেখুন।
  8. /ip dhcp-client add interface=ether1 disabled=no
  9. /ip address print দিয়ে IP যাচাই করুন।
  10. /ping 8.8.8.8 দিয়ে নেটওয়ার্ক টেস্ট করুন।

সফলতার মাপকাঠি

ক্লিনআপ

VM বন্ধ করুন এবং Proxmox থেকে মুছে ফেলুন অথবা স্ন্যাপশট নিন।

২৭ ইন্টারমিডিয়েট ল্যাব

▼

Intermediate

উদ্দেশ্য

দুটি নেটওয়ার্ক ব্রিজ (vmbr0 + vmbr1) ব্যবহার করে CHR-এ দুটি নেটওয়ার্ক কনফিগার করা।

টপোলজি

Proxmox vmbr0 (WAN) ↔ CHR ether1 (DHCP)
Proxmox vmbr1 (LAN) ↔ CHR ether2 (192.168.10.1/24)

ধাপ

  1. Proxmox-এ qm set 100 --net1 virtio,bridge=vmbr1 চালান।
  2. CHR-এ /ip address add address=192.168.10.1/24 interface=ether2।
  3. ফায়ারওয়াল রুল যোগ করুন (WinBox শুধু ether2 থেকে)।
  4. admin পাসওয়ার্ড পরিবর্তন করুন।

সফলতার মাপকাঠি

২৮ অ্যাডভান্সড ল্যাব

▼

Advanced

উদ্দেশ্য

CHR-কে DHCP সার্ভার হিসেবে কনফিগার করে vmbr1-এ ক্লায়েন্টকে IP দেওয়া এবং NAT-এর মাধ্যমে ইন্টারনেট অ্যাক্সেস দেওয়া।

ধাপ

  1. CHR-এ ether1 = vmbr0 (WAN), ether2 = vmbr1 (LAN)।
  2. /ip address add address=10.10.10.1/24 interface=ether2
  3. /ip pool add name=lab-pool ranges=10.10.10.100-10.10.10.200
  4. /ip dhcp-server add interface=ether2 address-pool=lab-pool disabled=no
  5. /ip dhcp-server network add address=10.10.10.0/24 gateway=10.10.10.1
  6. /ip firewall nat add chain=srcnat out-interface=ether1 action=masquerade
  7. vmbr1-এ ক্লায়েন্ট VM বুট করে DHCP থেকে IP পেয়েছে কিনা দেখুন।

চ্যালেঞ্জ

ক্লায়েন্ট থেকে ping 8.8.8.8 কাজ করছে কিন্তু ping google.com কাজ করছে না — কেন? সমাধান করুন।

২৯ ইন্টারভিউ প্রশ্ন

▼

বিগিনার

প্রশ্ন ১: CHR কী?
উত্তর: Cloud Hosted Router — RouterOS-এর ভার্চুয়াল সংস্করণ।

প্রশ্ন ২: Proxmox-এ CHR-এর জন্য কোন ফাইল ফরম্যাট ডাউনলোড করতে হয়?
উত্তর: Raw disk image (.img.zip), .npk নয়।

প্রশ্ন ৩: CHR-এর ডিফল্ট লগইন কী?
উত্তর: admin, পাসওয়ার্ড খালি।

ইন্টারমিডিয়েট

প্রশ্ন ৪: Proxmox-এ CHR কনসোল কালো কেন?
উত্তর: সিরিয়াল কনসোল কনফিগার করা হয়নি। --serial0 socket --vga serial0 যোগ করতে হবে [citation:10]।

প্রশ্ন ৫: qm importdisk কী করে?
উত্তর: ইমেজকে Proxmox স্টোরেজে ইমপোর্ট করে এবং VM-এ অ্যাটাচ করার জন্য প্রস্তুত করে।

প্রশ্ন ৬: ফ্রি লাইসেন্সের থ্রুপুট সীমা কত?
উত্তর: ১ Mbps প্রতি ইন্টারফেস।

অ্যাডভান্সড

প্রশ্ন ৭: একই ডিস্ক থেকে একাধিক VM বানালে লাইসেন্স সমস্যা কেন হয়?
উত্তর: System ID একই থাকে। /system/license/generate-new-id দিয়ে নতুন ID তৈরি করতে হয় (শুধু ফ্রি লাইসেন্সে)।

প্রশ্ন ৮: ট্রায়াল মেয়াদ শেষ হলে কী হয়?
উত্তর: CHR চলতে থাকে কিন্তু ১ Mbps-এ ফিরে যায় এবং RouterOS আপগ্রেড করা যায় না।

প্রশ্ন ৯: Proxmox-এ CHR-এর জন্য কোন NIC টাইপ সর্বোত্তম?
উত্তর: virtio — প্যারাভার্চুয়ালাইজড, সর্বোত্তম পারফরম্যান্স।

৩০ চ্যালেঞ্জ

▼

পরিস্থিতি: আপনাকে Proxmox-এ একটি CHR কনফিগার করতে বলা হলো যেখানে:

  • net0 = vmbr0 (WAN, DHCP)
  • net1 = vmbr1 (LAN, 10.10.10.0/24, DHCP সার্ভার)
  • net2 = vmbr2 (ম্যানেজমেন্ট, 192.168.100.0/24, WinBox শুধু এখান থেকে)

শর্ত: admin পাসওয়ার্ড অবশ্যই পরিবর্তন করতে হবে। LAN ক্লায়েন্টরা NAT-এর মাধ্যমে ইন্টারনেট পাবে। WinBox শুধুমাত্র net2 থেকে অ্যাক্সেসযোগ্য হবে।

💡 হিন্ট ১

NAT-এর জন্য /ip firewall nat add chain=srcnat out-interface=ether1 action=masquerade

💡 হিন্ট ২

WinBox সীমিত করতে /ip service set winbox address=192.168.100.0/24

💡 হিন্ট ৩

DHCP সার্ভার ether2-তে দিন, pool 10.10.10.100-200, gateway 10.10.10.1
