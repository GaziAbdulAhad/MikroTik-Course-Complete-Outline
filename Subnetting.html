১ ওভারভিউ ও স্কোপ

▼

Subnetting (সাবনেটিং) হলো একটি বড় IP নেটওয়ার্ককে ছোট ছোট 논리적 নেটওয়ার্কে (সাবনেট) ভাগ করার প্রক্রিয়া। এটি নেটওয়ার্কের পারফরম্যান্স, সিকিউরিটি এবং ম্যানেজমেন্ট উন্নত করে। MikroTik RouterOS v7-এ WinBox GUI-এর মাধ্যমে সহজেই Subnetting ও VLSM (Variable Length Subnet Mask) কনফিগার করা যায়।

স্কোপ (Scope)

  • অন্তর্ভুক্ত: IPv4 Subnetting-এর মূল ধারণা, CIDR নোটেশন, Subnet Mask ক্যালকুলেশন, VLSM, WinBox-এ Subnet কনফিগারেশন, DHCP Pool তৈরি, ভেরিফিকেশন এবং Troubleshooting।
  • বাদ: IPv6 Subnetting, Supernetting, জটিল রাউটিং প্রোটোকল।
  • ভার্সন: RouterOS v7.x, WinBox GUI। CLI কমান্ডও উল্লেখ করা হয়েছে যাতে GUI ও CLI-এর সম্পর্ক বোঝা যায়।
ℹ️ তথ্য MikroTik RouterOS-এ প্রতিটি ইন্টারফেসে একাধিক IP অ্যাড্রেস দেওয়া যায় (Secondary IP)। তবে একই সাবনেটের একাধিক IP দিলে সতর্কতা আসে। ভিন্ন সাবনেটের IP দিয়ে একই ইন্টারফেসে একাধিক নেটওয়ার্ক চালানো যায়।

২ পাঁচটি প্রধান স্তম্ভ (Five Priority Pillars)

▼
  1. ধারণা ও কনফিগারেশন: Subnetting কী, কেন দরকার, এবং WinBox-এ ধাপে ধাপে কনফিগারেশন।
  2. ভেন্ডর-স্পেসিফিক কমান্ড: MikroTik RouterOS v7-এর সঠিক CLI কমান্ড এবং WinBox মেনু পাথ।
  3. হ্যান্ডস-অন ল্যাব: বাস্তব টপোলজি, IP প্ল্যান, কনফিগারেশন এবং টেস্ট।
  4. ভেরিফিকেশন ও Troubleshooting: প্রতিটি ধাপ যাচাই এবং সমস্যা সমাধান।
  5. বেস্ট প্র্যাকটিস ও সতর্কতা: IP প্ল্যানিং, সাবনেট ডিজাইন এবং প্রোডাকশন সতর্কতা।

৪ আর্কিটেকচার ও টপোলজি

▼

Internet → Router (192.168.10.0/24)

Subnets:
VLAN 10: 192.168.10.0/25 (Admin)
VLAN 20: 192.168.10.128/26 (Sales)
VLAN 30: 192.168.10.192/27 (Support)

কম্পোনেন্ট

  • Network Address: সাবনেটের প্রথম ঠিকানা (হোস্ট ব্যবহার করা যায় না)।
  • Broadcast Address: সাবনেটের শেষ ঠিকানা (সব হোস্টকে মেসেজ পাঠাতে ব্যবহৃত)।
  • Usable Host Range: Network ও Broadcast-এর মাঝের ঠিকানাগুলো।
  • Subnet Mask: নেটওয়ার্ক ও হোস্ট অংশ আলাদা করে।

৫ ELI10 ও ELI15

▼

ELI10 (সহজ উপমা)

ভাবুন, আপনার একটি বড় বাড়ি আছে যেখানে ২৫৪টি রুম আছে। সবাই একসাথে থাকলে জামেলা, গোলমাল আর প্রাইভেসি থাকে না। তাই আপনি বাড়িটিকে ছোট ছোট ফ্ল্যাটে ভাগ করলেন — যেমন ফ্ল্যাট A-তে ১২৬টি রুম, ফ্ল্যাট B-তে ৬২টি রুম, ফ্ল্যাট C-তে ৩০টি রুম। প্রতিটি ফ্ল্যাটের নিজস্ব গেট, নিজস্ব নিয়ম। এটাই Subnetting — একটি বড় নেটওয়ার্ককে ছোট ছোট 논িक নেটওয়ার্কে ভাগ করা।

ELI15 (প্রযুক্তিগত)

IPv4 অ্যাড্রেস ৩২-বিট। একটি /24 সাবনেটে ২৫৬টি ঠিকানা থাকে (২৫৪টি ব্যবহারযোগ্য)। Subnetting মানে হলো হোস্ট বিট থেকে কিছু বিট ধার (borrow) করে সাবনেট তৈরি করা। উদাহরণ: /24 থেকে ১টি বিট ধার করলে /25 হয় — তখন ২টি সাবনেট তৈরি হয়, প্রতিটিতে ১২৬টি ব্যবহারযোগ্য হোস্ট। VLSM-এ প্রতিটি সাবনেটের প্রয়োজন অনুযায়ী ভিন্ন সাবনেট মাস্ক ব্যবহার করা যায়। MikroTik-এ WinBox → IP → Addresses-এ CIDR নোটেশন (যেমন 192.168.10.1/25) দিয়ে সাবনেট কনফিগার করা হয়।

৭ কেন ও কীভাবে (WHY & HOW)

▼

কেন Subnetting?

  • প্রদর্শনশীলতা: বড় ব্রডকাস্ট ডোমেইন ছোট হলে নেটওয়ার্ক দ্রুত হয়।
  • সিকিউরিটি: আলাদা সাবনেটে ফায়ারওয়াল রুল প্রয়োগ করা যায়।
  • ম্যানেজমেন্ট: প্রতিটি বিভাগের জন্য আলাদা নেটওয়ার্ক।
  • IP সাশ্রয়: VLSM দিয়ে প্রয়োজন অনুযায়ী IP বরাদ্দ।

কীভাবে কাজ করে?

  1. একটি বড় নেটওয়ার্ক (যেমন /24) নিন।
  2. কয়টি সাবনেট দরকার এবং প্রতিটিতে কয়টি হোস্ট দরকার নির্ধারণ করুন।
  3. সূত্র: 2^n ≥ সাবনেট সংখ্যা (n = ধার করা বিট)।
  4. সূত্র: 2^h - 2 ≥ হোস্ট সংখ্যা (h = অবশিষ্ট হোস্ট বিট)।
  5. নতুন সাবনেট মাস্ক বের করুন এবং প্রতিটি সাবনেটের রেঞ্জ নির্ধারণ করুন।
  6. WinBox-এ ইন্টারফেসে IP দিন এবং DHCP সার্ভার কনফিগার করুন।

১১ CIDR ও Subnet Mask

▼

CIDR নোটেশন

CIDR (Classless Inter-Domain Routing) নোটেশন হলো সাবনেট মাস্ক প্রকাশের সংক্ষিপ্ত রূপ। যেমন /24 মানে প্রথম ২৪টি বিট নেটওয়ার্ক অংশ, বাকি ৮টি বিট হোস্ট অংশ।

Binary to CIDR
255.255.255.0   = 11111111.11111111.11111111.00000000 = /24
255.255.255.128 = 11111111.11111111.11111111.10000000 = /25
255.255.255.192 = 11111111.11111111.11111111.11000000 = /26
255.255.255.224 = 11111111.11111111.11111111.11100000 = /27
ℹ️ তথ্য MikroTik WinBox-এ IP অ্যাড্রেস দেওয়ার সময় শুধু CIDR নোটেশন ব্যবহার করলেই হয় — যেমন 192.168.10.1/24। WinBox স্বয়ংক্রিয়ভাবে সাবনেট মাস্ক (255.255.255.0) হিসাব করে নেয়।

১২ WinBox-এ Subnet কনফিগার

▼

ধাপ ১: Subnetted IP কনফিগার

WinBox → IP → Addresses → +:

WinBox — Add Subnetted IP
Address:   192.168.10.1/25
Network:   192.168.10.0 (auto)
Interface: ether2
Comment:   Admin Subnet

ধাপ ২: একাধিক সাবনেট কনফিগার

RouterOS v7 — Multiple Subnets
/ip address add address=192.168.10.1/25 interface=ether2 comment="Admin"
/ip address add address=192.168.10.129/26 interface=ether3 comment="Sales"
/ip address add address=192.168.10.193/27 interface=ether4 comment="Support"

ধাপ ৩: DHCP Pool (প্রতি সাবনেটে)

RouterOS v7 — DHCP Pools
/ip pool add name=admin_pool ranges=192.168.10.2-192.168.10.126
/ip pool add name=sales_pool ranges=192.168.10.130-192.168.10.190
/ip pool add name=support_pool ranges=192.168.10.194-192.168.10.222

ধাপ ৪: DHCP Server (প্রতি সাবনেটে)

RouterOS v7 — DHCP Servers
/ip dhcp-server add name=dhcp_admin interface=ether2 address-pool=admin_pool disabled=no
/ip dhcp-server add name=dhcp_sales interface=ether3 address-pool=sales_pool disabled=no
/ip dhcp-server add name=dhcp_support interface=ether4 address-pool=support_pool disabled=no

ধাপ ৫: DHCP Network (গেটওয়ে)

RouterOS v7 — DHCP Networks
/ip dhcp-server network add address=192.168.10.0/25 gateway=192.168.10.1 dns-server=8.8.8.8
/ip dhcp-server network add address=192.168.10.128/26 gateway=192.168.10.129 dns-server=8.8.8.8
/ip dhcp-server network add address=192.168.10.192/27 gateway=192.168.10.193 dns-server=8.8.8.8
⚠️ সতর্কতা প্রতিটি সাবনেটের জন্য আলাদা DHCP সার্ভার ও নেটওয়ার্ক তৈরি করতে হবে। একই ইন্টারফেসে একাধিক DHCP সার্ভার দিলে কনফ্লিক্ট হতে পারে — তাই আলাদা ইন্টারফেস বা VLAN ব্যবহার করুন।

১৩ VLSM কনফিগারেশন

▼

VLSM উদাহরণ

আপনার কাছে 192.168.20.0/24 নেটওয়ার্ক আছে। প্রয়োজন:

  • Dept A = 120 host → /25 (126 hosts)
  • Dept B = 60 host → /26 (62 hosts)
  • Dept C = 30 host → /27 (30 hosts)
VLSM Calculation
Dept A: 192.168.20.0/25    (Hosts: .1 - .126)
Dept B: 192.168.20.128/26  (Hosts: .129 - .190)
Dept C: 192.168.20.192/27  (Hosts: .193 - .222)
RouterOS v7 — VLSM Configuration
# Dept A
/ip address add address=192.168.20.1/25 interface=ether2 comment="Dept A"
/ip pool add name=poolA ranges=192.168.20.2-192.168.20.126
/ip dhcp-server add name=dhcpA interface=ether2 address-pool=poolA disabled=no
/ip dhcp-server network add address=192.168.20.0/25 gateway=192.168.20.1

# Dept B
/ip address add address=192.168.20.129/26 interface=ether3 comment="Dept B"
/ip pool add name=poolB ranges=192.168.20.130-192.168.20.190
/ip dhcp-server add name=dhcpB interface=ether3 address-pool=poolB disabled=no
/ip dhcp-server network add address=192.168.20.128/26 gateway=192.168.20.129

# Dept C

সাবনেট সিকিউরিটি

  • Subnet Isolation: আলাদা সাবনেটে ফায়ারওয়াল রুল দিয়ে ট্রাফিক নিয়ন্ত্রণ।

  • DHCP Snooping: অননুমোদিত DHCP সার্ভার ব্লক।
  • VLAN: সাবনেটকে VLAN দিয়ে আরও আইসোলেট করুন।

২১ ফেইলিওর সিমুলেশন

▼

সিমুলেশন ১: ভুল সাবনেট মাস্ক

সিম্পটম: একই সুইচে থাকা দুটি PC একে অপরকে ping করতে পারে না।
কারণ: একটিতে /24, অন্যটিতে /25 মাস্ক।
ফিক্স: দুই ডিভাইসে একই সাবনেট মাস্ক দিন।

সিমুলেশন ২: ডুপ্লিকেট IP

সিম্পটম: মাঝে মাঝে সংযোগ বিচ্ছিন্ন হয়।
কারণ: দুই ডিভাইসে একই IP।
ফিক্স: DHCP দিয়ে স্বয়ংক্রিয় IP দিন, অথবা স্ট্যাটিক IP ডকুমেন্ট করুন।

সিমুলেশন ৩: গেটওয়ে ভুল

সিম্পটম: LAN-এ ping যায়, কিন্তু ইন্টারনেটে যায় না।
কারণ: DHCP-এ গেটওয়ে সেট করা হয়নি।
ফিক্স: /ip dhcp-server network-এ gateway যোগ করুন।

সিমুলেশন ৪: DHCP পুল শেষ

সিম্পটম: নতুন ক্লায়েন্ট IP পাচ্ছে না।
চেক: /ip pool print → used: 100/100।
ফিক্স: পুল রেঞ্জ বাড়ান।

সিমুলেশন ৫: WinBox লকআউট

সিম্পটম: LAN IP পরিবর্তনের পর WinBox সংযোগ নেই।
ফিক্স: কনসোল/সিরিয়াল থেকে /ip address print চেক করুন এবং নতুন IP-তে WinBox সংযোগ করুন।

▼

প্রথম চেক: ক্লায়েন্টরা IP পেয়েছে কিনা দেখুন — /ip dhcp-server lease print।

প্রতিরোধ: নতুন সাবনেট যোগ করার সময় DHCP নেটওয়ার্ক গেটওয়ে ও DNS সেট করা বাধ্যতামূলক করুন।

২৭ ইন্টারভিউ প্রশ্ন

▼

বিগিনার

প্রশ্ন ১: Subnetting কী?
উত্তর: একটি বড় IP নেটওয়ার্ককে ছোট 논িक নেটওয়ার্কে ভাগ করার প্রক্রিয়া।

প্রশ্ন ২: /24 সাবনেটে কতটি ব্যবহারযোগ্য হোস্ট?
উত্তর: ২৫৪টি।

প্রশ্ন ৩: /25 সাবনেটে কতটি হোস্ট?
উত্তর: ১২৬টি।

ইন্টারমিডিয়েট

প্রশ্ন ৪: VLSM কী?
উত্তর: Variable Length Subnet Mask — প্রয়োজন অনুযায়ী ভিন্ন সাবনেট মাস্ক ব্যবহার।

প্রশ্ন ৫: /26 সাবনেটের নেটওয়ার্ক ও ব্রডকাস্ট ঠিকানা কী?
উত্তর: 192.168.10.0/26-এ নেটওয়ার্ক .0, ব্রডকাস্ট .63।

প্রশ্ন ৬: WinBox-এ সাবনেট কনফিগার কোথায়?
উত্তর: IP → Addresses।

অ্যাডভান্সড

প্রশ্ন ৭: Subnetting-এর সুবিধা কী?
উত্তর: ব্রডকাস্ট ডোমেইন ছোট, সিকিউরিটি, ম্যানেজমেন্ট, IP সাশ্রয়।

প্রশ্ন ৮: একই ইন্টারফেসে একাধিক সাবনেট দেওয়া যায়?
উত্তর: হ্যাঁ, ভিন্ন সাবনেটের IP দেওয়া যায় (Secondary IP)।

প্রশ্ন ৯: DHCP পুল শেষ হলে কী হয়?
উত্তর: নতুন ক্লায়েন্ট IP পায় না। পুল রেঞ্জ বাড়াতে হবে।

  • একটি /24 নেটওয়ার্ক (192.168.10.0/24) কে তিনটি সাবনেটে ভাগ করতে হবে।
