কী শিখবেন

এই হ্যান্ডবুকে আপনি শিখবেন কীভাবে MikroTik Cloud Hosted Router (CHR) কে VMware Workstation-এ ইনস্টল ও কনফিগার করতে হয়। CHR হলো RouterOS-এর ভার্চুয়াল সংস্করণ, যা x86_64 ভার্চুয়াল এনভায়রনমেন্টে চলে এবং ফিজিক্যাল রাউটারের মতোই routing, firewall, VPN ইত্যাদি ফিচার প্রদান করে

স্কোপ: CHR ডাউনলোড, VMware VM তৈরি, ডিস্ক ইমেজ অ্যাটাচ, নেটওয়ার্ক অ্যাডাপ্টার ম্যাপিং, প্রথম বুট, পাসওয়ার্ড সেট, লাইসেন্সিং, বেসিক ভেরিফিকেশন, ট্রাবলশুটিং এবং প্রোডাকশন কনসিডারেশন।

বহির্ভূত: ESXi/vSphere-ভিত্তিক ডিপ্লয়মেন্ট, Hyper-V, KVM, VirtualBox, এবং উন্নত রাউটিং প্রোটোকল কনফিগারেশন (BGP/OSPF) — এগুলো 별도의 টপিক।

ℹ️ অনুমান ব্যবহারকারী নির্দিষ্ট করে নি, তাই ধরে নেওয়া হয়েছে: RouterOS v7.x Stable, VMware Workstation Pro/Player (Windows/Linux হোস্ট), এবং ল্যাব/লার্নিং এনভায়রনমেন্ট।

৩. ELI10 — একদম সহজ ভাষায়

▼

CHR কী? CHR (Cloud Hosted Router) হলো MikroTik RouterOS-এর একটি ভার্চুয়াল সংস্করণ। এটি কোনো ফিজিক্যাল বক্স নয় — এটি একটি ভার্চুয়াল মেশিন (VM) হিসেবে আপনার কম্পিউটারে চলে।

উপমা: ধরুন আপনার একটি ফিজিক্যাল MikroTik রাউটার আছে। সেটার সব ফিচার (routing, firewall, NAT) আপনি আপনার ল্যাপটপে একটি সফটওয়্যার হিসেবে চালাতে চান। CHR ঠিক সেটাই করে — এটি VMware-এর ভেতরে একটি "ভার্চুয়াল রাউটার" তৈরি করে দেয়।

কেন VMware? VMware Workstation আপনার কম্পিউটারে একাধিক ভার্চুয়াল মেশিন চালানোর সুবিধা দেয়। CHR-এর জন্য MikroTik একটি রেডিমেড .vmdk ডিস্ক ইমেজ দেয়, যা সরাসরি VMware-এ অ্যাটাচ করলেই হয়ে যায় — কোনো ISO ইনস্টলেশন লাগে না

মনে রাখুন: CHR প্রথমবার চালু হলে এটি Free লাইসেন্স-এ চলে, যার গতি সীমা প্রতি ইন্টারফেসে ১ Mbps

৪. ELI15 — প্রকৃত কার্যপ্রণালী

▼

CHR মূলত একটি x86_64 Linux-ভিত্তিক ভার্চুয়াল অ্যাপ্লায়েন্স। MikroTik আপনাকে একটি প্রি-বিল্ট ডিস্ক ইমেজ (.vmdk, .img, .vdi, .vhdx) দেয়। এই ইমেজটি কোনো ইনস্টলার নয় — এটি একটি সম্পূর্ণ বুটেবল ডিস্ক

VMware Workstation-এ প্রক্রিয়া:

  1. MikroTik ওয়েবসাইট থেকে .vmdk ফাইল ডাউনলোড করুন।
  2. VMware-এ একটি নতুন VM তৈরি করুন (Guest OS: Other Linux 64-bit)।
  3. VMware-এর ডিফল্ট ভার্চুয়াল ডিস্কটি মুছে ফেলুন এবং পরিবর্তে ডাউনলোড করা .vmdk ফাইলটি "Existing Disk" হিসেবে অ্যাটাচ করুন।
  4. VM চালু করুন — RouterOS বুট হবে এবং আপনি admin (পাসওয়ার্ড ছাড়া) দিয়ে লগইন করতে পারবেন

নেটওয়ার্কিং: VMware-এ প্রতিটি ভার্চুয়াল নেটওয়ার্ক অ্যাডাপ্টার একটি নির্দিষ্ট VMnet-এর সাথে ম্যাপ হয়। যেমন, VMnet 8 সাধারণত NAT (ইন্টারনেট অ্যাক্সেস), আর VMnet 1 বা Host-only অ্যাডাপ্টার ল্যাব নেটওয়ার্কের জন্য ব্যবহৃত হয়। CHR-এর ভেতরে এই অ্যাডাপ্টারগুলো ether1, ether2 ইত্যাদি হিসেবে দেখা যাবে

⚠️ গুরুত্বপূর্ণ CHR ডিস্ক ইমেজ শুধুই একটি ডিস্ক — এটি সরাসরি ডাবল-ক্লিক করে চালানো যায় না। এটি অবশ্যই একটি VM-এর সাথে সংযুক্ত করতে হবে

৬. পূর্বশর্ত ও ডিপেন্ডেন্সি

▼

হোস্ট সিস্টেম

  • 64-bit প্রসেসর যাতে virtualization সাপোর্ট আছে (VT-x/AMD-V)
  • RAM: কমপক্ষে 256 MB (সুপারিশ 1024 MB)
  • ডিস্ক: কমপক্ষে 128 MB
  • VMware Workstation 12 বা তার পরবর্তী

সফটওয়্যার

  • MikroTik CHR VMDK ইমেজ (RouterOS v7.x Stable)
  • Winbox (ঐচ্ছিক, GUI ম্যানেজমেন্টের জন্য)

নেটওয়ার্ক প্ল্যানিং

VM তৈরির আগে কোন VMnet কোন কাজে ব্যবহার করবেন তা ঠিক করুন। সাধারণ ল্যাব সেটআপ:

  • VMnet 8 (NAT): WAN — ইন্টারনেট অ্যাক্সেস
  • VMnet 1 (Host-only): LAN — ম্যানেজমেন্ট/টেস্টিং
ℹ️ INFO VMware Workstation-এ Virtual Network Editor খুলে VMnet-গুলো কনফিগার করা যায়। Host-only VMnet-এ একটি নির্দিষ্ট সাবনেট (যেমন 192.168.100.0/24) সেট করে রাখলে ট্রাবলশুটিং সহজ হয়

৭. CHR ডাউনলোড ও VM তৈরি

▼

ধাপ ১: CHR VMDK ডাউনলোড

MikroTik ডাউনলোড পেজে যান → Cloud Hosted Router সেকশন → .vmdk ফাইল ডাউনলোড করুন

ধাপ ২: VMware-এ নতুন VM

VMware Workstation খুলুন → File → New Virtual Machine → Custom configuration।

  • Guest OS: Other Linux (64-bit) নির্বাচন করুন (RouterOS প্রিসেট লিস্টে নেই)।
  • VM Name: যেমন CHR-Lab-01
  • Memory: 1024 MB (সুপারিশ)
  • Disk: ডিফল্ট ডিস্কটি মুছে ফেলুন। তারপর "Use an existing virtual disk" নির্বাচন করে ডাউনলোড করা .vmdk ফাইলটি পয়েন্ট করুন।
VM সেটিংস সারাংশ
Name: CHR-Lab-01
Guest OS: Other Linux (64-bit)
Memory: 1024 MB
Disk: Existing VMDK (CHR image)
Network Adapter 1: VMnet 8 (NAT)
Network Adapter 2: VMnet 1 (Host-only)

ধাপ ৩: নেটওয়ার্ক অ্যাডাপ্টার

VM সেটিংসে গিয়ে প্রয়োজন অনুযায়ী নেটওয়ার্ক অ্যাডাপ্টার যোগ করুন। ল্যাবের জন্য কমপক্ষে ২টি (WAN + LAN) রাখুন। অ্যাডাপ্টারের ক্রম অনুযায়ী CHR-এ ether1, ether2 তৈরি হবে।

⚠️ নেটওয়ার্ক অ্যাডাপ্টার টাইপ RouterOS v7-এ vmxnet3 ব্যবহার করলে Fast Path সাপোর্ট পাওয়া যায়, যা পারফরম্যান্স বাড়ায়

ধাপ ৪: প্রথম বুট

VM পাওয়ার অন করুন। কনসোল খুলুন। RouterOS বুট হবে এবং লগইন প্রম্পট দেখাবে।

প্রথম লগইন
MikroTik Login: admin
Password: (ফাঁকা, শুধু Enter চাপুন)

লগইনের পর RouterOS লাইসেন্স দেখতে চাইবে — n চেপে স্কিপ করুন। তারপর একটি শক্তিশালী পাসওয়ার্ড সেট করুন।

৮. কমান্ড এনসাইক্লোপিডিয়া (RouterOS v7)

▼

কমান্ড #1 — সিস্টেম আইডি ও লাইসেন্স

MikroTik RouterOS v7 — System ID
/system license print

উদ্দেশ্য: CHR-এর System ID এবং বর্তমান লাইসেন্স লেভেল দেখা।
প্রত্যাশিত: system-id: XXXXXXXXXXXX এবং level: free দেখাবে

কমান্ড #2 — ইন্টারফেস তালিকা

MikroTik RouterOS v7 — Interfaces
/interface print

উদ্দেশ্য: ether1, ether2 ইত্যাদি ইন্টারফেস দেখা এবং সেগুলো running কিনা যাচাই।

কমান্ড #3 — IP ঠিকানা অ্যাসাইন

MikroTik RouterOS v7 — IP Address
/ip address add address=192.168.100.1/24 interface=ether2 comment="LAN Management"

উদ্দেশ্য: LAN ইন্টারফেসে ম্যানেজমেন্ট IP সেট করা।

কমান্ড #4 — DHCP সার্ভার

MikroTik RouterOS v7 — DHCP Server
/ip pool add name=lan-pool ranges=192.168.100.100-192.168.100.200
/ip dhcp-server add interface=ether2 address-pool=lan-pool disabled=no
/ip dhcp-server network add address=192.168.100.0/24 gateway=192.168.100.1

উদ্দেশ্য: LAN-এ DHCP সার্ভার চালু করা যাতে ক্লায়েন্টরা অটো IP পায়।

কমান্ড #5 — NAT (মাসকারেড)

MikroTik RouterOS v7 — NAT
/ip firewall nat add chain=srcnat out-interface=ether1 action=masquerade

উদ্দেশ্য: LAN ক্লায়েন্টদের WAN (ইন্টারনেট) অ্যাক্সেস দেওয়ার জন্য NAT।
⚠️ শর্ত: ether1 অবশ্যই DHCP ক্লায়েন্ট বা স্ট্যাটিক IP দিয়ে ইন্টারনেট-সংযুক্ত থাকতে হবে।

কমান্ড #6 — লাইসেন্স রিনিউ (ট্রায়াল)

MikroTik RouterOS v7 — License Renewal
/system license renew

উদ্দেশ্য: ৬০ দিনের ট্রায়াল লাইসেন্স অ্যাক্টিভেট করা। MikroTik.com অ্যাকাউন্টের ইউজারনেম/পাসওয়ার্ড লাগবে ⚠️: এটি শুধু Free লাইসেন্সে করা যায়। ইতিমধ্যে ট্রায়াল/পেইড থাকলে করবেন না।

গুরুত্বপূর্ণ সতর্কতা

  • System ID ক্লোনিং: VM ক্লোন করলে একই System ID হতে পারে। নতুন ট্রায়ালের জন্য /system license generate-new-id চালান (শুধু Free লাইসেন্সে)
  • ট্রায়াল মেয়াদ: ৬০ দিনের মধ্যে লাইসেন্স কিনতে না পারলে CHR আপগ্রেড করা যাবে না।
  • MTU: VMware ESXi-তে jumbo frame (9000) সাপোর্ট করে, কিন্তু ইন্টারফেস MTU পরিবর্তন করতে হয়
  • Paravirtualization: CHR কোনো paravirtualized প্ল্যাটফর্মে চলে না

১২. হ্যান্ডস-অন ল্যাব (Beginner → Advanced)

▼

ল্যাব ১: বেসিক নেটওয়ার্কিং (Beginner)

উদ্দেশ্য: CHR-এ দুটি ইন্টারফেস কনফিগার করে LAN থেকে WAN-এ পিং করা।

টপোলজি:

Topology (English Labels)
[Host PC] --- (VMnet 1) --- [CHR ether2: 192.168.100.1/24]
                                     |
                              [CHR ether1: DHCP Client]
                                     |
                                (VMnet 8 NAT) --- Internet

ধাপ:

  1. ether1-এ DHCP ক্লায়েন্ট: /ip dhcp-client add interface=ether1 disabled=no
  2. ether2-এ IP: /ip address add address=192.168.100.1/24 interface=ether2
  3. NAT: /ip firewall nat add chain=srcnat out-interface=ether1 action=masquerade
  4. হোস্ট থেকে CHR-এ পিং: ping 192.168.100.1
  5. CHR থেকে ইন্টারনেট পিং: /ping 8.8.8.8

সফলতার মাপকাঠি: হোস্ট → CHR এবং CHR → ইন্টারনেট পিং সফল।

ল্যাব ২: DHCP + DNS (Intermediate)

উদ্দেশ্য: LAN ক্লায়েন্টদের অটো IP ও DNS প্রদান।

DHCP + DNS কনফিগারেশন
/ip pool add name=lan-pool ranges=192.168.100.100-192.168.100.150
/ip dhcp-server add interface=ether2 address-pool=lan-pool disabled=no
/ip dhcp-server network add address=192.168.100.0/24 gateway=192.168.100.1 dns-server=8.8.8.8,1.1.1.1
/ip dns set servers=8.8.8.8,1.1.1.1 allow-remote-requests=yes

টেস্ট: হোস্ট মেশিনের নেটওয়ার্ক অ্যাডাপ্টার VMnet 1-এ DHCP-তে সেট করুন, তারপর ipconfig /renew (Windows) বা dhclient (Linux) চালান।

ল্যাব ৩: ফায়ারওয়াল বেসিক (Advanced)

উদ্দেশ্য: WAN থেকে LAN-এ অনুপ্রবেশ ব্লক করা।

Basic Firewall Rules
/ip firewall filter add chain=input in-interface=ether1 action=drop comment="Drop WAN Input"
/ip firewall filter add chain=input connection-state=established,related action=accept comment="Allow Established"
⚠️ সতর্কতা এই রুলটি প্রয়োগের আগে নিশ্চিত করুন যে আপনার ম্যানেজমেন্ট অ্যাক্সেস (Winbox/SSH) LAN-এর মাধ্যমে হচ্ছে। ভুল করলে WAN থেকে লকআউট হতে পারেন। প্রথমে action=accept দিয়ে টেস্ট করুন, তারপর drop করুন।

১৩. ইন্টারভিউ প্রশ্ন ও উত্তর

▼

Beginner

প্রশ্ন ১: CHR কী?
উত্তর: CHR (Cloud Hosted Router) হলো MikroTik RouterOS-এর ভার্চুয়াল সংস্করণ, যা x86_64 হাইপারভাইজারে চলে

প্রশ্ন ২: CHR-এর ডিফল্ট ইউজারনেম কী?
উত্তর: admin, পাসওয়ার্ড ফাঁকা।

প্রশ্ন ৩: CHR-এর Free লাইসেন্সে গতি সীমা কত?
উত্তর: প্রতি ইন্টারফেসে ১ Mbps

Intermediate

প্রশ্ন ৪: VMware-এ CHR-এর জন্য কোন ডিস্ক ফরম্যাট ব্যবহার হয়?
উত্তর: .vmdk (VMware Virtual Machine Disk)।

প্রশ্ন ৫: CHR-এ Fast Path সাপোর্ট করে কোন নেটওয়ার্ক অ্যাডাপ্টার?
উত্তর: RouterOS v7-এ vmxnet3 এবং virtio-net

Advanced

প্রশ্ন ৬: VM ক্লোন করলে কী সমস্যা হতে পারে?
উত্তর: একই System ID তৈরি হতে পারে, যা লাইসেন্সিংয়ে সমস্যা করে। সমাধান: Free লাইসেন্সে /system license generate-new-id

প্রশ্ন ৭: CHR-এর ট্রায়াল লাইসেন্স কত দিনের?
উত্তর: ৬০ দিন।
