১ ওভারভিউ ও স্কোপ

▼

WinBox হলো MikroTik RouterOS ম্যানেজ করার জন্য একটি ফাস্ট ও সিম্পল GUI ইউটিলিটি। এটি মূলত একটি নেটিভ Win32/Win64 বাইনারি, তবে Linux ও macOS-এ Wine এমুলেশন সফটওয়্যার দিয়ে চালানো যায় । WinBox দিয়ে আপনি RouterOS-এর প্রায় সব কনফিগারেশন GUI-তে করতে পারেন — IP অ্যাড্রেস, ফায়ারওয়াল, রাউটিং, কিউইউ, VPN ইত্যাদি।

স্কোপ (Scope)

  • অন্তর্ভুক্ত: Windows, Linux (Wine) ও macOS-এ WinBox ইনস্টলেশন, প্রথম সংযোগ, Neighbors ও MAC-ভিত্তিক সংযোগ, নিরাপদ কনফিগারেশন, Troubleshooting এবং বেস্ট প্র্যাকটিস।
  • বাদ: RouterOS-এর ভেতরের বিস্তারিত রাউটিং প্রোটোকল কনফিগারেশন (BGP/OSPF), WebFig, SSH, API।
  • ভার্সন: WinBox v4.x (সর্বশেষ stable)। WinBox v3-এর সাথে গুরুত্বপূর্ণ পার্থক্য থাকলে উল্লেখ করা হবে [citation:1]।
ℹ️ তথ্য WinBox v4 এখন Windows, macOS ও Linux-এর জন্য আলাদা নেটিভ বিল্ড সরবরাহ করে [citation:1]। Linux-এর জন্য নেটিভ বিল্ড থাকলেও, অনেক ব্যবহারকারী এখনও Wine-ভিত্তিক পুরনো পদ্ধতি ব্যবহার করেন। WinBox v4-এ macOS 12+ এবং Windows 10+ প্রয়োজন [citation:1]।

২ পাঁচটি প্রধান স্তম্ভ (Five Priority Pillars)

▼
  1. ধারণা ও ইনস্টলেশন: WinBox কী, কেন GUI, এবং প্রতিটি OS-এ ধাপে ধাপে ইনস্টলেশন।
  2. কমান্ড ও ইন্টারফেস: WinBox GUI-এর প্রতিটি অংশ, Neighbors, MAC সংযোগ, এবং CLI-এর সাথে সম্পর্ক।
  3. হ্যান্ডস-অন ল্যাব: প্রথম সংযোগ, Neighbors ডিসকভারি, MAC WinBox, এবং নিরাপদ কনফিগারেশন।
  4. ভেরিফিকেশন ও Troubleshooting: সংযোগ যাচাই এবং সাধারণ সমস্যা সমাধান।
  5. বেস্ট প্র্যাকটিস ও সতর্কতা: নিরাপদ WinBox ব্যবহার, MAC সার্ভার সীমিত করা, এবং প্রোডাকশন সতর্কতা।

৪ আর্কিটেকচার ও টপোলজি

▼

WinBox সংযোগের ধরন

WinBox Client → RouterOS (IP: 192.168.88.1:8291)

অথবা

WinBox Client → MAC (Layer 2) → RouterOS (MAC WinBox, UDP 20561)

কম্পোনেন্ট

  • WinBox Client: আপনার কম্পিউটারে চলা WinBox অ্যাপ্লিকেশন।
  • RouterOS Device: MikroTik রাউটার (ফিজিক্যাল বা ভার্চুয়াল)।
  • Management IP: রাউটারের IP ঠিকানা (TCP 8291)।
  • MAC WinBox: IP ছাড়াই Layer 2-এ MAC অ্যাড্রেস দিয়ে সংযোগ (UDP 20561) [citation:5]।

৫ ELI10 ও ELI15

▼

ELI10 (সহজ উপমা)

ভাবুন, আপনার MikroTik রাউটার হলো একটি বড় কন্ট্রোল প্যানেল। CLI (কমান্ড লাইন) দিয়ে সেই প্যানেল চালাতে অনেক কমান্ড মুখস্থ করতে হয়। WinBox হলো সেই প্যানেলের একটি রিমোট কন্ট্রোল — যেখানে বাটন, ট্যাব আর মেনু আছে। আপনি মাউস দিয়ে ক্লিক করে সহজেই সব কনফিগার করতে পারেন। যেমন স্মার্টফোনে অ্যাপ দিয়ে ফোন সেটিংস বদলানো সহজ, তেমনি WinBox দিয়ে রাউটার সেটিংস বদলানো সহজ।

ELI15 (প্রযুক্তিগত)

WinBox একটি Win32/Win64 বাইনারি অ্যাপ্লিকেশন যা RouterOS-এর সাথে TCP 8291 পোর্টে (অথবা MAC WinBox-এর ক্ষেত্রে UDP 20561) যোগাযোগ করে [citation:5]। WinBox v4-এ একটি MDI (Multiple Document Interface) ইন্টারফেস আছে — বাম পাশে সাইডবার মেনু, মাঝে ওয়ার্ক এরিয়া, উপরে টুলবার এবং নিচে রিসোর্স বার [citation:2]। Neighbors ট্যাব MNDP (MikroTik Neighbor Discovery Protocol) ব্যবহার করে নেটওয়ার্কে থাকা MikroTik ডিভাইসগুলো খুঁজে বের করে, এমনকি IP কনফিগার না থাকলেও MAC অ্যাড্রেস দিয়ে সংযোগ করা যায় [citation:5]। WinBox v3.14 থেকে অ্যাপ্লিকেশনটি Extended Validation সার্টিফিকেট দিয়ে সাইন করা হয়, যা নিরাপত্তা নিশ্চিত করে ।

৭ কেন ও কীভাবে (WHY & HOW)

▼

কেন WinBox?

  • সহজ: CLI কমান্ড মুখস্থ না করেই সব কনফিগার করা যায়।
  • দ্রুত: একই সাথে একাধিক উইন্ডো খুলে কাজ করা যায় (MDI)।
  • Neighbors: নেটওয়ার্কে থাকা ডিভাইস স্বয়ংক্রিয়ভাবে খুঁজে পায়।
  • MAC সংযোগ: IP কনফিগার না থাকলেও রাউটারে সংযোগ করা যায় — নতুন রাউটার সেটআপ বা রিকভারির জন্য অপরিহার্য [citation:5]।
  • ক্রস-প্ল্যাটফর্ম: Windows, Linux, macOS-এ চলে।

কীভাবে কাজ করে?

  1. WinBox অ্যাপ্লিকেশন চালু করা হয়।
  2. Connect To ফিল্ডে রাউটারের IP অথবা MAC অ্যাড্রেস দেওয়া হয়।
  3. Neighbors ট্যাব MNDP ব্রডকাস্টের মাধ্যমে নেটওয়ার্কের MikroTik ডিভাইসগুলো তালিকাভুক্ত করে।
  4. লগইন করার পর WinBox রাউটারের সাথে সেশন স্থাপন করে।
  5. প্রথমবার সংযোগে WinBox রাউটার থেকে প্লাগইন ডাউনলোড করে (কয়েক সেকেন্ড সময় লাগতে পারে)।
  6. এরপর সাইডবার মেনু থেকে যেকোনো কনফিগারেশন করা যায়।

৮ পূর্বশর্ত (Prerequisites)

macOS

নেটওয়ার্ক

  • TCP 8291 (IP WinBox) অথবা UDP 20561 (MAC WinBox) পোর্টে অ্যাক্সেস থাকতে হবে [citation:5]।

১০ Windows-এ ইনস্টলেশন

▼

ধাপ ১: ডাউনলোড

MikroTik-এর অফিসিয়াল ডাউনলোড পেজে যান এবং Windows (64-bit) নির্বাচন করুন [citation:1]।

Download URL
https://mikrotik.com/download/winbox/

ধাপ ২: এক্সট্রাক্ট

ডাউনলোড করা WinBox_Windows.zip ফাইলটি ডান-ক্লিক করে Extract All নির্বাচন করুন [citation:7]।

ধাপ ৩: চালু করুন

এক্সট্রাক্ট করা ফোল্ডারে WinBox.exe-তে ডাবল-ক্লিক করুন। Windows SmartScreen সতর্কতা দেখালে Allow বা More info → Run anyway নির্বাচন করুন [citation:7]।

ℹ️ তথ্য winget ব্যবহার করে ইনস্টল করতে চাইলে: winget install -e --id Mikrotik.Winbox [citation:12]।

১১ Linux (Wine)-এ ইনস্টলেশন

▼

পদ্ধতি ১: নেটিভ WinBox v4 (প্রস্তাবিত)

WinBox v4-এ Linux-এর জন্য নেটিভ 64-bit বিল্ড আছে [citation:1]।

Linux — Native WinBox
# ডাউনলোড করুন
wget https://download.mikrotik.com/winbox/4.4/WinBox_Linux.zip

# এক্সট্রাক্ট করুন
unzip WinBox_Linux.zip

# চালু করুন
chmod +x WinBox
./WinBox

পদ্ধতি ২: Wine দিয়ে পুরনো WinBox

নেটিভ বিল্ড না থাকলে Wine ব্যবহার করা যায় ।

Linux — Wine Installation
# Wine ইনস্টল করুন (Ubuntu/Debian)
sudo apt update
sudo apt install wine

# Microsoft ফন্ট প্যাক ইনস্টল করুন (টেক্সট ডিস্টর্শন এড়াতে)
sudo apt install ttf-mscorefonts-installer

# WinBox.exe ডাউনলোড করে চালান
wine WinBox.exe
⚠️ সতর্কতা Wine-এ Microsoft ফন্ট প্যাক ইনস্টল না করলে WinBox-এর টেক্সট বিকৃত দেখাতে পারে [citation:8]।

১২ macOS-এ ইনস্টলেশন

▼

WinBox v4 (Universal)

macOS 12+ এর জন্য নেটিভ WinBox v4 ডাউনলোড করুন [citation:1]।

macOS — Native WinBox
1. https://mikrotik.com/download/winbox/ থেকে WinBox.dmg ডাউনলোড করুন
2. DMG ফাইল মাউন্ট করুন
3. WinBox অ্যাপ্লিকেশন Applications ফোল্ডারে ড্র্যাগ করুন
4. Applications থেকে WinBox চালু করুন

পুরনো পদ্ধতি (Wine + WinBox64)

macOS 10.15 Catalina-তে 32-bit অ্যাপ সাপোর্ট বন্ধ হওয়ায় 64-bit Wine ও WinBox64.exe প্রয়োজন ।

⚠️ সতর্কতা WinBox v4 নেটিভ বিল্ড থাকায় macOS-এ Wine-এর প্রয়োজন নেই। শুধুমাত্র পুরনো সংস্করণের জন্য Wine ব্যবহার করুন।

১৩ প্রথম সংযোগ

▼

IP অ্যাড্রেস দিয়ে সংযোগ

  1. WinBox চালু করুন।
  2. Connect To ফিল্ডে রাউটারের IP দিন (যেমন 192.168.88.1)।
  3. Login ফিল্ডে ইউজারনেম দিন (ডিফল্ট admin)।
  4. Password ফিল্ডে পাসওয়ার্ড দিন (ডিফল্ট খালি)।
  5. Connect ক্লিক করুন।

Neighbors ট্যাব

WinBox-এর Login স্ক্রিনে Neighbors ট্যাব থাকে। এটি MNDP ব্রডকাস্টের মাধ্যমে নেটওয়ার্কের MikroTik ডিভাইসগুলো তালিকাভুক্ত করে। তালিকা থেকে ডিভাইস নির্বাচন করে Connect ক্লিক করলেই সংযোগ হয়ে যায় [citation:5]।

ℹ️ তথ্য প্রথমবার সংযোগে WinBox রাউটার থেকে প্লাগইন ডাউনলোড করে। এতে কয়েক সেকেন্ড সময় লাগতে পারে। এরপর সাইডবার মেনু সম্পূর্ণ দেখা যাবে।

১৪ Neighbors ও MAC সংযোগ

▼

MAC WinBox সংযোগ

IP কনফিগার না থাকলে বা IP ভুলে গেলে MAC অ্যাড্রেস দিয়ে WinBox সংযোগ করা যায় [citation:5]।

  1. WinBox Login স্ক্রিনে Neighbors ট্যাব খুলুন।
  2. তালিকায় ডিভাইসের MAC অ্যাড্রেস দেখাবে।
  3. MAC অ্যাড্রেসে ক্লিক করে Connect করুন।

RouterOS-এ MAC সার্ভার কনফিগার

RouterOS v7 — MAC WinBox Settings
# MAC WinBox স্ট্যাটাস দেখুন
/tool/mac-server/mac-winbox/print

# শুধুমাত্র LAN ইন্টারফেসে MAC WinBox অনুমোদন করুন
/tool/mac-server/mac-winbox/set allowed-interface-list=LAN
⚠️ সতর্কতা MAC WinBox UDP 20561 পোর্ট ব্যবহার করে। IP ফায়ারওয়াল রুল এই ট্রাফিক ব্লক করে না — এটি Layer 2-এ কাজ করে [citation:5]। MAC অ্যাক্সেস সীমিত করতে allowed-interface-list অথবা bridge filter ব্যবহার করুন।

১৫ নিরাপদ কনফিগারেশন

▼

WinBox পোর্ট পরিবর্তন

RouterOS v7 — Change WinBox Port
# WinBox পোর্ট পরিবর্তন (ডিফল্ট 8291)
/ip service set winbox port=8299

WinBox অ্যাক্সেস সীমিত

RouterOS v7 — Restrict WinBox to Management Subnet
/ip service set winbox address=192.168.88.0/24

অপ্রয়োজনীয় সার্ভিস বন্ধ

RouterOS v7 — Disable Insecure Services
/ip service disable telnet,ftp,www,api
🛡️ NOC টিপ প্রোডাকশনে MAC WinBox শুধুমাত্র ট্রাস্টেড ইন্টারফেসে সীমিত রাখুন। /tool/mac-server/mac-winbox/set allowed-interface-list=LAN — ডিফল্টভাবে LAN লিস্টে শুধু LAN bridge থাকে [citation:5]।

১৯ সিকিউরিটি

▼

WinBox সিকিউরিটি বেস্ট প্র্যাকটিস

  • ডিফল্ট পোর্ট পরিবর্তন: 8291-এর বদলে কাস্টম পোর্ট ব্যবহার করুন।
  • IP সীমিত: শুধুমাত্র ম্যানেজমেন্ট সাবনেট থেকে WinBox অ্যাক্সেস দিন।
  • MAC WinBox সীমিত: শুধুমাত্র LAN ইন্টারফেসে অনুমোদন করুন।
  • শক্তিশালী পাসওয়ার্ড: admin পাসওয়ার্ড অবশ্যই সেট করুন।
  • সার্ভিস বন্ধ: অপ্রয়োজনীয় সার্ভিস (telnet, ftp, www) বন্ধ রাখুন।
  • সার্টিফিকেট: WinBox v3.14+ EV সার্টিফিকেট দিয়ে সাইন করা — ডাউনলোডের সময় যাচাই করুন ।
🚨 বিপদ MAC WinBox IP ফায়ারওয়াল দ্বারা সুরক্ষিত নয়। UDP 20561 পোর্ট ব্লক করার IP রুল MAC অ্যাক্সেস বন্ধ করে না [citation:5]। MAC অ্যাক্সেস সীমিত করতে allowed-interface-list অথবা bridge filter ব্যবহার করুন।

২০ ফেইলিওর সিমুলেশন

▼

সিমুলেশন ১: Neighbors খালি

সিম্পটম: WinBox-এ কোনো ডিভাইস দেখা যাচ্ছে না।
কারণ: MNDP বন্ধ অথবা ফায়ারওয়াল ব্রডকাস্ট ব্লক করছে।
চেক: /ip neighbor print
ফিক্স: /ip neighbor discovery-settings set discover-interface-list=all

সিমুলেশন ২: IP WinBox Timeout

সিম্পটম: IP দিয়ে Connect করলে Timeout।
কারণ: WinBox সার্ভিস বন্ধ অথবা 8291 ফায়ারওয়ালে ব্লকড।
চেক: /ip service print
ফিক্স: /ip service enable winbox এবং ফায়ারওয়াল রুল চেক।

সিমুলেশন ৩: MAC WinBox কাজ করে না

সিম্পটম: MAC দিয়ে Connect করলে Timeout।
কারণ: MAC WinBox বন্ধ অথবা ইন্টারফেস লিস্টে নেই।
চেক: /tool/mac-server/mac-winbox/print
ফিক্স: /tool/mac-server/mac-winbox/set allowed-interface-list=LAN

সিমুলেশন ৪: Wine-এ WinBox ক্র্যাশ

সিমপটম: Linux-এ Wine দিয়ে WinBox চালু হচ্ছে না।
কারণ: Wine কনফিগারেশন সমস্যা অথবা 32/64-bit মিসম্যাচ।
ফিক্স: নেটিভ WinBox v4 Linux বিল্ড ব্যবহার করুন [citation:1]।

সিমুলেশন ৫: পাসওয়ার্ড ভুলে গেছেন

সিম্পটম: WinBox লগইন করতে পারছেন না।
কারণ: পাসওয়ার্ড পরিবর্তিত হয়েছে।
ফিক্স: রাউটারের কনসোলে (সিরিয়াল/VirtualBox/Proxmox) লগইন করে /password দিয়ে রিসেট করুন।

২১ বেস্ট প্র্যাকটিস

▼

ল্যাব vs প্রোডাকশন

দিকল্যাবপ্রোডাকশন
পাসওয়ার্ডডিফল্ট থাকতে পারেশক্তিশালী পাসওয়ার্ড বাধ্যতামূলক
WinBox পোর্টডিফল্ট 8291কাস্টম পোর্ট
IP সীমাসব IPশুধু ম্যানেজমেন্ট সাবনেট
MAC WinBoxচালুশুধু LAN-এ সীমিত
সার্ভিসসব চালুশুধু প্রয়োজনীয় সার্ভিস

মূল সুপারিশ

  • প্রথম দিনেই admin পাসওয়ার্ড সেট করুন।
  • WinBox পোর্ট পরিবর্তন করুন।
  • IP অ্যাক্সেস শুধু ম্যানেজমেন্ট সাবনেটে সীমিত করুন।
  • MAC WinBox শুধু LAN-এ অনুমোদন করুন।
  • অপ্রয়োজনীয় সার্ভিস বন্ধ রাখুন।

২২ NOC সিনারিও

▼

সিনারিও: একটি NOC-এ নতুন MikroTik রাউটার ইনস্টল করা হয়েছে। টেকনিশিয়ান WinBox দিয়ে সংযোগ করতে পারছেন না।

প্রথম চেক: WinBox Neighbors ট্যাব খালি।

রুট কজ: রাউটারের discover-interface-list ডিফল্ট LAN এবং টেকনিশিয়ানের কম্পিউটার WAN পোর্টে সংযুক্ত।

সমাধান: রাউটারের কনসোল থেকে /ip neighbor discovery-settings set discover-interface-list=all চালান, অথবা কম্পিউটার LAN পোর্টে সংযুক্ত করুন।

প্রতিরোধ: নতুন রাউটার সেটআপের সময় LAN পোর্টে সংযোগ করুন এবং MAC WinBox দিয়ে প্রাথমিক কনফিগার করুন।

Beginner

উদ্দেশ্য

Windows-এ WinBox ইনস্টল করে IP দিয়ে একটি MikroTik রাউটারে সংযোগ করা।

টপোলজি

Windows PC → RouterOS (192.168.88.1)

ধাপ

  3. WinBox.exe চালান।
  4. Connect To: 192.168.88.1
  5. Login: admin, Password: (খালি)
  6. Connect ক্লিক করুন।
  7. ড্যাশবোর্ড দেখা গেলে সফল।

Advanced

উদ্দেশ্য

WinBox অ্যাক্সেস শুধুমাত্র ম্যানেজমেন্ট সাবনেটে সীমিত করা এবং MAC WinBox শুধু LAN-এ অনুমোদন করা।

উত্তর: UDP 20561 পোর্টে MAC অ্যাড্রেস দিয়ে Layer 2-এ সংযোগ করে, IP কনফিগারেশন ছাড়াই [citation:5]।

প্রশ্ন ৫: Neighbors ট্যাব কী দেখায়?
উত্তর: MNDP ব্রডকাস্টের মাধ্যমে নেটওয়ার্কের MikroTik ডিভাইস তালিকা।

প্রশ্ন ৬: Linux-এ WinBox চালানোর দুটি পদ্ধতি কী?
উত্তর: নেটিভ WinBox v4 Linux বিল্ড অথবা Wine [citation:1]।

অ্যাডভান্সড

প্রশ্ন ৭: MAC WinBox কি IP ফায়ারওয়াল দিয়ে ব্লক করা যায়?
উত্তর: না, MAC WinBox Layer 2-এ কাজ করে। allowed-interface-list অথবা bridge filter দিয়ে সীমিত করতে হয় [citation:5]।

প্রশ্ন ৮: WinBox v4-এ Undo/Redo কতটি পরিবর্তন মনে রাখে?
উত্তর: সর্বোচ্চ ১০০টি [citation:2]।

প্রশ্ন ৯: macOS-এ WinBox চালানোর জন্য কী প্রয়োজন?
উত্তর: WinBox v4 নেটিভ বিল্ড (macOS 12+) অথবা পুরনো পদ্ধতিতে 64-bit Wine + WinBox64.exe [citation:1]।

২৭ চ্যালেঞ্জ

▼

পরিস্থিতি: আপনাকে একটি নতুন MikroTik রাউটার সেটআপ করতে বলা হলো যেখানে:

  • রাউটারের IP এখনও কনফিগার করা হয়নি।
  • আপনার কম্পিউটার LAN পোর্টে সংযুক্ত।
  • WinBox দিয়ে সংযোগ করে প্রাথমিক কনফিগার করতে হবে।
  • WinBox পোর্ট পরিবর্তন করতে হবে এবং IP অ্যাক্সেস সীমিত করতে হবে।
💡 হিন্ট ১

IP ছাড়া সংযোগের জন্য MAC WinBox ব্যবহার করুন — Neighbors ট্যাব থেকে MAC অ্যাড্রেসে ক্লিক করুন।

💡 হিন্ট ৩

IP সীমা: /ip service set winbox address=192.168.88.0/24
