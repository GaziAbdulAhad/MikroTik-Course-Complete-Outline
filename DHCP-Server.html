1. Overview + Scope + Assumptions

Assumptions: VENDOR = MikroTik; TOPIC = DHCP Server; VERSION = RouterOS v6 + v7 (differences marked); ENVIRONMENT = ISP/NOC; DEPTH = Extensive.

এই হ্যান্ডবুকটি MikroTik RouterOS-এ DHCP Server কনফিগারেশন, ভেরিফিকেশন, ট্রাবলশুটিং এবং ISP/NOC পরিবেশে প্রোডাকশন ডিপ্লয়মেন্টের সম্পূর্ণ গাইড। DHCP (Dynamic Host Configuration Protocol) হলো এমন একটি প্রোটোকল যা নেটওয়ার্কে ক্লায়েন্ট ডিভাইসকে স্বয়ংক্রিয়ভাবে IP অ্যাড্রেস, Subnet Mask, Gateway, DNS ইত্যাদি প্রদান করে।

কেন গুরুত্বপূর্ণ: ম্যানুয়াল IP কনফিগারেশন এড়িয়ে স্বয়ংক্রিয়ভাবে হাজারো ক্লায়েন্টকে দ্রুত নেটওয়ার্কে সংযুক্ত করা যায়। ISP/NOC-এ DHCP Server ব্যবহার করে গ্রাহকদের CPE (Customer Premises Equipment) অটো-প্রোভিশন করা হয়।

Scope

  • IPv4 DHCP Server (মূল ফোকাস)
  • DHCP Relay, DHCP Client, DHCP Alert
  • Lease Management, Static Lease, Scripting
  • Security (DHCP Snooping, Option 82)
  • ISP/NOC প্রোডাকশন প্যাটার্ন

Out of Scope (সংক্ষেপে উল্লেখ)

DHCPv6 Server/Client/PD সম্পূর্ণ আলাদা টপিক; এখানে শুধু IPv4 DHCP-এ ফোকাস।

5. ELI10 → ELI15 → Jargonize

ELI10 (10 বছরের বাচ্চাকে বোঝানো)

ভাবো তোমার ক্লাসে ৩০ জন বাচ্চা আছে। শিক্ষক প্রত্যেককে একটা করে রোল নম্বর দেন। DHCP Server হলো সেই শিক্ষক — কেউ ক্লাসে এলে তাকে অটোমেটিক একটা নম্বর (IP Address) দিয়ে দেন, আর বলে দেন "তোমার বাড়ি যাওয়ার রাস্তা (Gateway) এটা, আর ফোন নম্বর (DNS) এটা"।

ELI15 (15 বছরের কিশোরকে)

DHCP হলো একটি প্রোটোকল। যখন তুমি ল্যাপটপ নেটওয়ার্কে প্লাগ করো, তখন তোমার ল্যাপটপ একটি "DISCOVER" মেসেজ ব্রডকাস্ট করে। DHCP Server সেটা শুনে একটি IP অফার করে ("OFFER")। তুমি সেটা গ্রহণ করলে ("REQUEST") সার্ভার কনফার্ম করে ("ACK")। এই চার ধাপকে DORA বলে।

Jargonize (Engineer Voice)

DHCPv4 (RFC 2131) operates over UDP port 67 (server) and 68 (client). The server maintains a pool of addresses, assigns leases with configurable durations, and delivers network parameters via DHCP options (Option 3: Router, Option 6: DNS, Option 51: Lease Time). RouterOS implements a stateful DHCP server with lease database, static bindings, and event-driven scripting hooks.

6. WHY + HOW

কেন DHCP Server?

  • Automation: ম্যানুয়াল IP কনফিগার ছাড়াই শত শত ডিভাইস সংযুক্ত।
  • Consistency: ভুল IP, duplicate IP, ভুল gateway প্রতিরোধ।
  • Centralized Management: এক জায়গা থেকে সব ক্লায়েন্টের নেটওয়ার্ক প্যারামিটার নিয়ন্ত্রণ।
  • ISP Scale: গ্রাহক CPE অটো-প্রোভিশন, zero-touch installation।

কীভাবে কাজ করে (DORA)

StepMessageDirectionDescription
1DHCPDISCOVERClient → Broadcastক্লায়েন্ট IP চায়
2DHCPOFFERServer → Clientসার্ভার IP অফার করে
3DHCPREQUESTClient → Broadcastক্লায়েন্ট অফার গ্রহণ করে
4DHCPACKServer → Clientসার্ভার কনফার্ম করে

Lease সময় শেষ হওয়ার আগে ক্লায়েন্ট Renew করে (Unicast), ব্যর্থ হলে Rebind করে (Broadcast) [citation:1]।

10. Concept & Design

IP Pool

IP Pool হলো IP address-এর একটি রেঞ্জ যা DHCP Server বিতরণ করবে। একাধিক রেঞ্জ একসাথে দেওয়া যায় (comma-separated), কিন্তু non-overlapping হতে হবে [citation:9]।

/ip pool add name=dhcp-pool ranges=192.168.10.10-192.168.10.200

Best Practice: Gateway এবং Static Server-এর IP Pool-এর বাইরে রাখুন।

DHCP Network

DHCP Network নির্ধারণ করে কোন subnet-এ কোন gateway, DNS, NTP দেওয়া হবে। প্রতিটি subnet-এর জন্য একটি network entry থাকা উচিত।

/ip dhcp-server network add address=192.168.10.0/24 gateway=192.168.10.1 dns-server=8.8.8.8,1.1.1.1

DHCP Server

Server entry একটি interface-এর সাথে pool ও network-কে যুক্ত করে।

/ip dhcp-server add name=dhcp-lan interface=bridge-lan address-pool=dhcp-pool lease-time=1d disabled=no

Lease

Lease হলো একটি IP address-এর নির্দিষ্ট সময়ের বরাদ্দ। Static Lease দিয়ে নির্দিষ্ট MAC-কে নির্দিষ্ট IP দেওয়া যায়।

/ip dhcp-server lease add address=192.168.10.50 mac-address=AA:BB:CC:DD:EE:FF server=dhcp-lan comment="Printer Static"

DHCP Options

Option 3 (Router), Option 6 (DNS), Option 15 (Domain Name), Option 42 (NTP), Option 43 (Vendor Specific), Option 82 (Relay Agent Information) — ISP/NOC-এ CPE provisioning-এর জন্য Option 43/82 গুরুত্বপূর্ণ।

11. Basic → Intermediate → Advanced Configuration

Basic Configuration (Wizard)

দ্রুত সেটআপের জন্য Wizard:

/ip dhcp-server setup

Wizard ধাপে ধাপে interface, network, gateway, pool, DNS, lease time জিজ্ঞাসা করবে [citation:12][citation:15]।

Manual Configuration (Production-Ready)

# Step 1: Pool
/ip pool add name=pool-vlan100 ranges=10.100.0.10-10.100.0.250

# Step 2: Network
/ip dhcp-server network add address=10.100.0.0/24 gateway=10.100.0.1 dns-server=103.10.10.10,103.10.10.11

# Step 3: Server
/ip dhcp-server add name=dhcp-vlan100 interface=vlan100 address-pool=pool-vlan100 lease-time=12h disabled=no

# Step 4: Verify
/ip dhcp-server print
/ip dhcp-server lease print

Advanced: Static Lease + Rate Limit

/ip dhcp-server lease add address=10.100.0.50 mac-address=AA:BB:CC:11:22:33 server=dhcp-vlan100 rate-limit=10M/10M comment="Customer-001"

NOC ISP-তে প্রতি গ্রাহকের জন্য static lease + rate-limit একটি সাধারণ প্যাটার্ন।

Advanced: Lease Script (Auto-Queue)

/ip dhcp-server set dhcp-vlan100 lease-script=":if (\$leaseBound = 1) do={ /queue simple add name=(\"q-\" . \$leaseActIP) target=\$leaseActIP max-limit=10M/10M } else={ /queue simple remove [find name=(\"q-\" . \$leaseActIP)] }"

Note: Script variable-এ hyphen থাকলে $"lease-hostname" syntax ব্যবহার করতে হয় [citation:14]।

13. Configuration Safety + Backup + Rollback

  • Backup: /system backup save name=pre-dhcp-change — কনফিগ পরিবর্তনের আগে ব্যাকআপ নিন।
  • Export: /export file=dhcp-config — human-readable কনফিগ সংরক্ষণ।
  • Safe Mode: Winbox-এ "Safe Mode" চালু করে কনফিগ পরিবর্তন করুন; ভুল হলে reboot-এ আগের অবস্থায় ফিরে যাবে।
  • Rollback: /system backup load name=pre-dhcp-change অথবা /import file=dhcp-config।
Caveat: /export শুধু কনফিগ রিস্টোর করে, lease database নয়। বড় পরিবর্তনের আগে /ip dhcp-server lease print detail কপি করে রাখুন।

14. Verification Framework

  1. Server Status: /ip dhcp-server print → disabled=no?
  2. Pool Free: /ip pool used print → free addresses আছে?
  3. Network Match: /ip dhcp-server network print → gateway subnet-এ আছে?
  4. Lease Bound: /ip dhcp-server lease print → status=bound?
  5. End-to-End: Client থেকে ipconfig /renew (Windows) বা dhclient (Linux) চালিয়ে IP, Gateway, DNS যাচাই।

17. Security

DHCP Alert (Rogue Server Detection)

/ip dhcp-server alert add interface=bridge-lan valid-server=AA:BB:CC:DD:EE:FF alert-timeout=1m

নেটওয়ার্কে অন্য DHCP Server সাড়া দিলে alert দেবে [citation:7]।

Option 82 (Relay Agent Information)

ISP/NOC-এ গ্রাহকের physical port (Circuit ID) বা switch (Remote ID) চিহ্নিত করতে Option 82 ব্যবহার হয়। RouterOS v7-এ custom Option 82 সেট করা যায় [citation:13]।

/interface bridge port set [find interface=ether5] dhcp-agent-circuit-id="OLT-1-PON-3-ONU-42"

ADVANCED [VERSION-DEPENDENT] v7.23+

DHCP Snooping (v7.23+)

Bridge-এ DHCP Snooping চালু করে rogue DHCP server ব্লক করা যায় [citation:13]।

/interface bridge set bridge-lan dhcp-snooping=yes
Security Caveat: DHCP Server interface-এ arp=reply-only সেট করলে শুধু DHCP lease-ধারী ডিভাইস communicate করতে পারবে — এটি কড়া security কিন্তু static IP ডিভাইস কাজ করবে না [citation:7]।

18. Performance & Capacity

  • Lease Time: ছোট lease (1h-12h) = বেশি renew traffic; বড় lease (1d-7d) = IP pool দীর্ঘ সময় ধরে থাকে। ISP/NOC-এ সাধারণত 12h-1d।
  • Pool Size: একসাথে যত ক্লায়েন্ট থাকতে পারে তার চেয়ে অন্তত 20-30% বেশি IP রাখুন।
  • Scripting: Lease script-এ ভারী কাজ (HTTP fetch, complex loop) CPU বাড়ায়; সম্ভব হলে minimum রাখুন।
  • Logging: dhcp topic-এ debug log চালু থাকলে lease চক্রে CPU ও disk I/O বাড়ে।

21. Failure Simulations (≥5)

Failure #1: Pool Exhausted

Injection: Pool-এর সব IP lease করে ফেলুন (ranges=192.168.1.10-192.168.1.12 দিয়ে ৪টি ক্লায়েন্ট)।

Symptom: নতুন ক্লায়েন্ট IP পায় না; /ip dhcp-server lease print-এ waiting lease দেখা যায়।

Fix: Pool size বাড়ান অথবা expired lease পরিষ্কার করুন।

Failure #2: Gateway Subnet-এর বাইরে

Injection: network add address=192.168.1.0/24 gateway=10.0.0.1।

Symptom: ক্লায়েন্ট IP পায় কিন্তু default route unresolved [citation:1]।

Fix: Gateway subnet-এর ভিতরে সেট করুন।

Failure #3: Rogue DHCP Server

Injection: নেটওয়ার্কে একটি পুরনো modem DHCP চালু রাখুন।

Symptom: ক্লায়েন্ট ভুল subnet-এর IP পায়; /ip dhcp-server alert print-এ alert।

Fix: Rogue server বন্ধ করুন; DHCP Snooping চালু করুন (v7.23+) [citation:13]।

Failure #4: Interface-এ IP নেই

Injection: DHCP Server interface থেকে IP address সরিয়ে ফেলুন।

Symptom: Server চলছে কিন্তু lease bound হচ্ছে না।

Fix: Interface-এ IP address পুনরায় assign করুন [citation:15]।

Failure #5: Lease Script Error

Injection: Lease script-এ undefined variable ব্যবহার করুন।

Symptom: Lease bound হচ্ছে কিন্তু script-এর কাজ (queue creation) হচ্ছে না; /log print where topics~"script"-এ error [citation:14]।

Fix: Script syntax যাচাই করুন; $"lease-hostname" hyphen variable-এর জন্য quotes ব্যবহার করুন।

22. Recovery Procedures

  1. Emergency Reset: /ip dhcp-server disable [find] → সমস্যা আইসোলেট করুন → ঠিক করে আবার enable।
  2. Lease Database Clear: /ip dhcp-server lease remove [find dynamic=yes] — শুধু dynamic lease মুছবে।
  3. Config Rollback: /system backup load name=pre-dhcp-change।
  4. Rogue Server Isolation: Switch port shutdown অথবা bridge DHCP Snooping enable।

23. Best Practices & Caveats

  • ✅ এক interface-এ এক DHCP Server — একাধিক server conflict তৈরি করে [citation:7]।
  • ✅ Gateway ও Static Server-এর IP Pool-এর বাইরে রাখুন।
  • ✅ ISP/NOC-এ প্রতি VLAN-এর জন্য আলাদা Pool + Network + Server।
  • ✅ Rogue DHCP detection-এর জন্য /ip dhcp-server alert সবসময় চালু রাখুন।
  • ✅ Lease Script-এ error handling (:onerror) যোগ করুন।
  • ❌ Lease time খুব ছোট (<5m) দেবেন না — renew storm তৈরি হবে।
  • ❌ DHCP Server interface-এ arp=reply-only না বুঝে দেবেন না — static IP ডিভাইস disconnect হবে [citation:7]।
  • ❌ DNS-এ public resolver (8.8.8.8) ISP/NOC-এ ব্যবহার করবেন না — local caching DNS ব্যবহার করুন।

26. Beginner Lab

Objective

একটি interface-এ সাধারণ DHCP Server কনফিগার করা এবং ক্লায়েন্ট IP পাচ্ছে কিনা যাচাই করা।

Topology

[MikroTik]---(ether2)---[Laptop]

IP Plan

  • MikroTik ether2: 192.168.1.1/24
  • Pool: 192.168.1.10-192.168.1.100
  • Gateway: 192.168.1.1
  • DNS: 8.8.8.8

Configuration

/ip address add address=192.168.1.1/24 interface=ether2
/ip pool add name=lab-pool ranges=192.168.1.10-192.168.1.100
/ip dhcp-server network add address=192.168.1.0/24 gateway=192.168.1.1 dns-server=8.8.8.8
/ip dhcp-server add name=lab-dhcp interface=ether2 address-pool=lab-pool lease-time=1h disabled=no

Verification

Laptop-এ ipconfig /renew (Windows) চালান; 192.168.1.x/24, gateway 192.168.1.1 পাওয়া উচিত। MikroTik-এ /ip dhcp-server lease print দিয়ে bound lease দেখুন।

Failure Injection

DHCP Server disable করুন; Laptop আবার renew করলে 169.254.x.x পাবে।

Challenge

Static lease দিয়ে Laptop-এর MAC-কে 192.168.1.50 দিন।

27. Intermediate Lab

Objective

Topology

Objective

Configuration

Failure Injection

Script-এ $leaseActIP-এর জায়গায় $wrongVar দিয়ে দেখুন error log-এ কী আসে [citation:14]।

31. Interview Questions

Beginner (10)

  1. DHCP-এর পূর্ণরূপ কী? — Dynamic Host Configuration Protocol।
  2. DORA কী? — Discover, Offer, Request, Acknowledge।
  3. DHCP Server কোন port ব্যবহার করে? — UDP 67 (server), 68 (client)।
  4. MikroTik-এ DHCP Server চালু করার আগে কী লাগে? — Interface-এ IP address [citation:15]।
  5. IP Pool কী? — DHCP যে range থেকে IP দেয় [citation:9]।
  6. Lease Time কী? — একটি IP কতক্ষণ ক্লায়েন্টের কাছে থাকবে।
  7. Static Lease কেন ব্যবহার করবেন? — নির্দিষ্ট MAC-কে সবসময় একই IP দিতে।
  8. DHCP Network entry-তে gateway কী? — ক্লায়েন্টের default gateway IP।
  9. DHCP Server disabled থাকলে ক্লায়েন্ট কী পায়? — 169.254.x.x (APIPA)।
  10. এক interface-এ একাধিক DHCP Server চালানো যাবে? — না, conflict হবে [citation:7]।

Intermediate (10)

  1. DHCP Relay কীভাবে কাজ করে? — Client-এর broadcast request-কে unicast-এ DHCP Server-এ পাঠায় [citation:5]।
  2. Relay-এ local-address কেন দরকার? — DHCP Server-কে relay চিনতে সাহায্য করে।
  3. Option 82 কী? — Relay Agent Information, Circuit ID + Remote ID।
  4. Lease renew ও rebind-এর পার্থক্য? — Renew unicast (T1), rebind broadcast (T2)।
  5. Pool empty হলে কী হয়? — নতুন ক্লায়েন্ট IP পায় না, waiting lease তৈরি হয়।
  6. /ip dhcp-server alert কেন? — Rogue DHCP Server detect করতে।
  7. Lease Script-এ $leaseBound=0 মানে? — Lease release/expiry [citation:14]।
  8. DHCP Client add-default-route কী করে? — Server-প্রদত্ত gateway দিয়ে default route বসায় [citation:1]।
  9. v6 vs v7 DHCP-এ মূল পার্থক্য? — v7-এ DHCP Snooping, add-dns-entries, custom Option 82।
  10. Gateway subnet-এর বাইরে হলে? — Default route unresolved [citation:1]।

Advanced (10)

  1. DHCP Snooping কীভাবে rogue server ঠেকায়? — Untrusted port-এ DHCP Offer block করে।
  2. Option 82 Circuit ID-তে কী রাখা যায়? — OLT/ONU/Port ID (ISP-তে subscriber চিহ্নিত করতে)।
  3. Lease Script-এ $"lease-hostname" কেন quotes দরকার? — Hyphen variable-এর জন্য [citation:14]।
  4. BOOTP support কখন dynamic করবেন? — পুরনো BOOTP-only ডিভাইস থাকলে [citation:14]।
  5. ARP reply-only-এর সুবিধা ও ঝুঁকি? — শুধু DHCP lease-ধারী communicate; static IP disconnect।
  6. DHCP Server-এ rate-limit কীভাবে কাজ করে? — Lease-এ rate-limit সেট করলে dynamic queue তৈরি হয়।
  7. Multi-VLAN DHCP-এ কী সতর্কতা? — প্রতি VLAN-এ আলাদা Pool+Network+Server; overlap নয়।
  8. Lease Database backup কীভাবে? — /ip dhcp-server lease print detail অথবা backup-এ থাকে।
  9. DHCP Server-এ delay-threshold কেন? — নির্দিষ্ট সময়ের কম বয়সী request উপেক্ষা করে (relay-এ)।
  10. Production-এ DNS 8.8.8.8 কেন নয়? — Latency, privacy, ISP caching DNS-এর সুবিধা।

Production / RCA

  1. গ্রাহক বলে "মাঝে মাঝে IP পায় না"। আপনার ধাপ? — Lease waiting check → Pool free → Log → Torch → Alert।
  2. Duplicate IP conflict রিপোর্ট। RCA? — Static IP pool-এর ভিতরে, rogue server, অথবা stale lease [citation:7]।
  3. Lease Script হঠাৎ কাজ করা বন্ধ করল। কী দেখবেন? — /log print where topics~"script", variable name, syntax [citation:14]।

32. Final Challenge + Hints

Challenge: একটি MikroTik রাউটারে ৩টি VLAN (100, 200, 300)-এর জন্য DHCP Server কনফিগার করুন। VLAN 100-এ rate-limit 10M/10M সহ static lease, VLAN 200-এ dynamic lease, VLAN 300-এ শুধু BOOTP disabled + DHCP Snooping। Rogue DHCP alert সব VLAN-এ চালু থাকবে।

💡 Hints (ক্লিক করুন)
  • প্রতি VLAN-এ /ip pool, /ip dhcp-server network, /ip dhcp-server আলাদা।
  • Static lease-এ rate-limit=10M/10M।
  • bootp-support=none VLAN 300-এ।
  • /interface bridge set [find name=br-lan] dhcp-snooping=yes।
  • /ip dhcp-server alert add interface=vlanX valid-server=...।
